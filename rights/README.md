# 윤리시티: AI 도입 심의위원회 — 인권 보장 (`/rights/`)

중·고등학생이 **윤리시티 AI 윤리위원회의 청소년 위원**이 되어, 안면인식 AI를 건물 출입·채용·치안에 도입할지 심의하고 **인권 보장 정책 권고안**을 쓰는 탐험형 게임입니다. 회의실과 현장(도서관·AI 실습실·중앙마당)을 걸어 다니며 증언과 자료를 모으고, 데이터를 해석하고, 1차 결정과 최종 결정을 비교합니다.

> 핵심 질문: 안면인식 AI를 **어디까지** 허용해야 할까? 모든 사람의 인권을 지키려면 **어떤 조건**이 필요할까?

- 대상: 중·고등학생 / 약 25분 / 프롤로그 → 1장 건물 출입 → 2장 채용 → 3장 치안 → 에필로그(권고안)
- 도입·조건부 도입·미도입 중 무엇을 골라도 성공·실패가 아닙니다. 판정 효과는 데이터 해석(사실 확인) 문항에만 씁니다.
- 기관·사례·수치는 모두 수업용 가상 자료입니다. 서버·로그인·외부 전송 없음.

## 실행

정적 파일입니다. `index.html`을 파일로 직접 열어도(`file://`) 동작합니다. 서버로 보려면:

```bash
node rights/tests/serve.mjs 8080      # → http://127.0.0.1:8080/rights/
```

## 공통 팩 사용

`/shared/ethicity-elementary-common-v1/`을 복사하지 않고 상대 경로로 불러옵니다(`common.css` → `manifest.js` → `common.js`). 캐릭터·배경·아이콘·효과·효과음은 모두 공통 팩 그대로입니다.

| 쓰임 | 공통 ID |
|---|---|
| 장소 | `classroom`(위원회 회의실) · `library`(1장) · `ai_lab`(2장) · `courtyard`(3장) |
| 인물 | 학생 5명 중 플레이어 1명 + 동료 위원 2명, `teacher`(사무국장), `librarian`(시설 관리자), `robot`(기록 보조) |
| 그 밖의 이해관계자 | 얼굴 없는 진술 카드(`person` 아이콘) — 개발사·인권 전문가·지원자·피해 시민 등 |
| 효과 | 자료 획득 `clue`, 데이터 확인 `correct`, 다시 살펴보기 `retry`, 장 완료 `key`, 이동 `door` |

- 공통 팩에 없는 것: CCTV 시험 장치(픽셀 좌표 코드로 `js/stage.js`에서 그림), 자료 카드·면접 화면·경보 화면(DOM).
- 걷기 영역은 manifest의 예제 `walkAreas`가 아니라 `js/data.js`의 `ROOMS.walk`(배경을 직접 재서 정한 바닥·길)입니다. 가구 위·뒤로는 걷지 않게 막아 앞뒤 순서 문제를 없앴습니다.
- 화면 속 학교 이름에 '초등학교'를 쓰지 않습니다(중등편).

## 조작

- 방향키·WASD로 걷기, `Space`/`Enter`로 말 걸기·조사하기. 화면을 누르면 그곳으로 걸어갑니다.
- `목적지로 바로 가기`는 다음 조사 지점(또는 출입구 → 지도)으로 데려갑니다. 키보드 없이 끝까지 할 수 있습니다.
- 세로 휴대폰에서는 무대가 보일 때 가로 모드를 권합니다('세로로 계속하기' 가능).
- 메뉴: 대사 속도, 움직임 줄이기, 효과음(기본 꺼짐), 처음 화면, 처음부터, 이 게임 기록 지우기.

## 기록과 통합

- 근거는 **키워드 선택 필수 + 한 줄 글은 선택**(100자, 권고안 문항 200자). 이름·연락처를 쓰지 말라는 안내를 붙입니다.
- 저장: `ethicity.rights.progress.v1`(단계·조사한 곳·결정·권고안), `ethicity.rights.settings.v1`. 이 기기에만 저장되고 단계마다 저장해 이어 하기를 지원합니다.
- 통합 이벤트(`parent.postMessage` + `window`의 `ethicity` CustomEvent): `ethicity:ready`, `ethicity:progress`(프롤로그·각 장·에필로그 끝, `total: 5`), `ethicity:complete`(`result: { completed: true }` — 선택·글은 넣지 않음).
- 결과 화면: 판단의 특징(신중한 도입/권리 우선 + 판단 발전/근거 유지), 우리가 발견한 것, 선택 경로, 권고안 복사·인쇄, 교실 토론 질문.

## 파일

| 파일 | 내용 |
|---|---|
| `js/data.js` | 대사·자료 카드·문항·장면 좌표·장 흐름(내용 정본) |
| `js/stage.js` | 1280×720 무대 축소, 걷기 격자·경로 탐색, 조사 표시 |
| `js/talk.js` | 대화창(공통 초상화 + `.ee-speech`) |
| `js/panels.js` | 결정·데이터 해석·생각 문항·분류·권고안 등 활동 패널 |
| `js/flow.js` | 단계 실행·저장·이어 하기·통합 이벤트 |
| `js/app.js` | 시작 화면·메뉴·가로 모드 안내·결과 화면 |


## 결정 사항

- 공통 에셋: `/shared/ethicity-elementary-common-v1/` 초등 팩을 그대로 사용한다(캐릭터·배경·UI 재디자인 없음).
- 학교 이름: 화면에 학교 이름이 나오면 '초등학교' 대신 '학교'로 쓴다.
- 화면 방향: 1280×720 무대를 비율 유지로 축소하고, 세로 휴대폰에서는 가로 모드 권장 안내를 띄운다.
- 배역: 청소년 위원 구성(권장안 A). 성인 이해관계자는 새로 그리지 않고 얼굴 없는 진술 카드로 표현한다.
- 근거 입력: 키워드 선택 필수 + 글 입력 선택.
- 이름 바꿔 부르기: 공통 캐릭터 `jiho`는 '하늘', `haneul`은 '지호'로 부른다(그림·ID는 공통 팩 그대로, `js/data.js`의 `RENAME`).
