# 공통 시각 규칙

## 기준

초등용 윤리시티 1.0의 기준은 이 팩의 새봄 캐릭터, 교실 배경, 공통 말풍선입니다. 개별 게임 담당자는 에셋의 위치·대사·미션을 변경하되, 배경이나 인물의 표현을 임의로 다른 스타일로 교체하지 않습니다.

## 색과 화면

- 논리 화면은 1280 × 720입니다. 실제 화면에서는 비율을 유지하며 축소합니다.
- 잉크 #294b40, 크림 #fff9e7, 세이지 #a8bb8c, 금색 #f3cf72, 하늘색 #72b7c4, 주황갈색 #bf7865를 기본으로 사용합니다.
- 간격은 8px의 배수를 기준으로 사용합니다. 조작 버튼의 실제 화면 크기는 최소 44px을 확보합니다.
- 큰 지도와 캐릭터는 image-rendering: pixelated 또는 Canvas의 imageSmoothingEnabled=false로 표시합니다.
- UI 문장은 실제 한글 텍스트로 표시합니다. 긴 문장을 그림 파일에 넣지 않습니다.

## 캐릭터

- 캐릭터별 의상·머리 모양을 유지합니다. 새로운 인물은 신체 비율과 외곽선·색상 수를 공통 시트와 대조합니다.
- 지도 좌표는 발 기준점으로 통일합니다. 학생의 권장 축척은 0.75~0.9, 성인은 0.85~1.0, 로봇은 0.6~0.7입니다.
- 걷기는 6fps를 기준으로 합니다. 정지할 때는 1번 프레임을 씁니다. 각 원본의 걷기 표현에는 작은 형태 변화가 있으므로 정지 화면을 프레임별로 확대해 다시 그리기보다 제공된 애니메이션으로 확인합니다.
- 대화용 얼굴은 제공된 4가지 표정을 사용합니다. 지도와 대화창에서 같은 ID의 인물을 사용합니다.

## 공통 UI

말풍선·버튼·아이콘의 외곽선과 색상은 runtime/common.css를 공유합니다. 기본·선택·비활성·성공·다시 살펴보기 상태를 색상뿐 아니라 문구나 기호로 함께 구분합니다. 키보드 초점 표시를 제거하지 않습니다.

## 이야기 속 자료

게임 안의 독서기록장·포스터·사진 등은 ‘등장인물이 보는 자료’로서 별도의 그림 재료를 표현할 수 있습니다. 이를 감싸는 창·버튼·아이콘·닫기 동작은 공통 UI를 사용합니다. 자료 내부의 그림체와 게임 전체 화면의 그림체를 구분해 관리합니다.

## 추가 에셋

새 에셋은 담당자마다 따로 배포하지 않고 공통 팩의 ID·파일명·manifest에 등록합니다. 변경 시 버전을 올리고 바뀐 파일과 적용된 게임을 기록합니다. 1.0에는 별도의 표정 전환 애니메이션이나 행동(조사·앉기·점프)은 포함하지 않습니다.
