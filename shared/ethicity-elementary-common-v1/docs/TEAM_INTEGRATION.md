# 팀 적용 순서

1. 팀장이 이 팩의 캐릭터·배경·UI를 확인해 공통 1.0 기준으로 채택합니다.
2. 저장소에 예를 들어 `assets/ethicity-common/` 폴더를 만들고 팩 구조를 유지해 넣습니다.
3. 각 게임의 기존 색상·글꼴·버튼을 공통 CSS로 연결합니다.
4. 지도의 인물은 `drawCharacter`, 대화창은 같은 ID의 `drawPortrait`를 사용합니다.
5. 선택한 장소의 배경을 연결하고 NPC·단서·출입구 좌표와 충돌 영역을 정합니다.
6. 단서·정답·재확인·열쇠·문 열기 효과를 해당 게임의 이벤트에 연결합니다.
7. 교사용 화면도 동일한 UI 토큰과 아이콘을 사용하되, 집계 화면의 글씨 크기와 표 가독성을 우선합니다.
8. 수정된 각 게임을 실제 학생 기기에서 확인한 뒤 팀 배포 방식으로 게시합니다.

에셋은 표시 자료이므로 그 자체에 Firebase가 필요하지 않습니다. 교사·학생의 응답·진행 상황 동기화는 각 게임의 기존 Firebase 또는 다른 서버 코드를 유지합니다. 이 팩의 미리보기는 서버 연결이나 실제 수업 방 생성을 수행하지 않습니다.
