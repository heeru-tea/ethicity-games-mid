# 계획: 단계 시작 전 설명을 결과 화면으로 옮기기 (2026-11-01)

지시서: 사용자 작업 지시 「"이번 정류장은…" 단계 시작 전 설명 줄이기」. 0단계 조사(스크래치 step0-report.md)를 근거로 한다.
원칙: 시뮬레이션·수요·비용·점수·밸런스 숫자는 그대로. 화면 배치와 문구만. 학습 내용(사례·질문·출처)은 위치만 옮긴다.

## 0단계 판정
- 「다음에는 누구의 이동을 살필까요?」 선택은 **효과 없음**(s.reflections 저장만, 자유 서술을 덮어씀) →
  결과 화면 「생각해 보기」 질문의 두 가지 선택형 답(더 많은 사람을 빠르게 / 오래 기다린 사람부터)으로 바꾸고 글쓰기 칸은 선택 사항.
  고른 답은 `s.choices[단계]`에 따로 저장(자유 서술 `s.reflections`를 건드리지 않음) → 다음 단계 지도 HUD 「이번 목표: …」.

## 흐름(새 규칙)
- 1단계: 타이틀 → 인트로 컷 4장(그대로) → 지도 계획 화면. 「첫 운행을 준비해요」 패널·첫 노선 모달 없음.
  지도 위 코치 말풍선 + 손가락(정류장 두 곳 누르기)만. 도움말 「첫 노선 안내 다시 보기」는 코치를 다시 띄움.
- 2단계+: 결과 → 「N단계로」 → (새 인물이 있는 단계만) 컷 1장(머리에 「3단계 · 변화기」, 대사 25자 안팎, 건너뛰기) → 지도.
  성찰 화면·「마을이 달라졌어요」 없음. 컷 원문 대사는 화면 낭독용 사본과 텍스트 모드 단계 안내에 남김.
- `App.go('reveal'|'reflect')`는 모두 계획 화면으로(Session.beginPlan). Session 상태 기계(reveal 단계)는 그대로.
- 지도 도착 신호: 배너 1줄(「3단계 · 변화기 · 신도시가 생겼어요 · 버스 +1」, 첫 클릭·3초 뒤 사라짐, aria-live),
  새 정류장 강조 고리(2.5초) + 「새 정류장」 배지, 새 버스 대기 칸 반짝임, 새 인물 얼굴은 출발 정류장에(기존 얼굴층).

## 상시 HUD
- 지도 위 인물 칩 줄 `#people-hud`(계획·운행, 지도·텍스트 모드 모두): [얼굴] 나래 09:03 외곽 마을→병원 0/4, 「기준 달성 불가」.
- 칩·지도 얼굴을 누르면 출발·도착 고리 + 이을 노선 경로 굵은 선 깜빡임(없으면 굵은 점선 + 「잇는 노선 없음」).
- 운행 중에도 얼굴 유지(syncStage가 운행 중에도 setFaces, 얼굴 층 표시).
- 「기준 달성 불가」 = 누적 완료 + 남은 단계 < 기준 (Narrative.criterionState, 순수 함수).

## 규칙·재정 설명
- 도움말에 「규칙과 재정」 절(지원금·공공서비스 수행분·임차·재정 규칙·대기 기준·이동 요청·학기 말 기준)을 세션 값으로 채움.
- 처음 만질 때 한 줄 팁 1회(ethicity.publicness.seenTips): 임차 「빌린 버스는 이번 단계만 써요.」, 수지·잔액, 공공서비스 고리, 인물 칩(대기 기준).
- 텍스트 모드 계획 패널 맨 위 `#stage-brief`: 이번 단계 바뀐 것·오늘 요청·학기 말 기준·새 인물 원문 대사(시각적으로 뺀 문장 보존).

## 결과 화면(기본 순서)
1. 한 줄 요약 + 큰 숫자 2개(도착률, 이번 단계 수지) — 라벨 붙임.
2. 인물 카드: 만족/불만족 + 구체 이유 1줄(어느 이동·어디서 얼마나·만차·노선 없음, 노선 버스 수·간격), 누적 n/m, 기준 달성 불가.
   누르면 카드 안 작은 지도(SVG)에서 그 구간 강조.
3. 이번 운행에서 생긴 일(돌발 수요·청원·긴급 조정, 시각, 최대 3줄).
4. 생각해 보기: 이번 결과와 잇는 한 줄 + 그 단계 사례 카드(문구·출처 그대로) + 단계 질문 + 두 선택형 답 + 글쓰기(선택).
   n단계 결과 = learning[n−1](1단계 결과에 의료 알고리즘 사례). 랜덤 8단계는 사례 없음(질문만).
5. 「자세히」(점수 두 칸·대기·지역별·노선 이용·운행 기록·예상과 실제·생활권 표·운행 중 들린 말(연속 반복 ×N)·재정) — 다음 단계 버튼은 하단 고정 바.
- 미니멀 화면도 같은 구조(옛 「오늘의 이동」 재구성은 끔).
