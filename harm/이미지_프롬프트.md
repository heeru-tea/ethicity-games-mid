# 침해금지 편 실감판 · 힉스필드 배경 이미지 프롬프트

만든 이미지는 `침해금지편_실감판/bg/` 폴더에 아래 **파일 이름 그대로** 넣으면 게임에 자동으로 들어갑니다. 넣지 않은 장면은 지금의 기본 그림이 그대로 나와요.

## 가장 간단한 방법 (합성 단서 찾기 장면만, 이미지 2장)

아래 두 프롬프트를 **그대로 복사해서** 힉스필드에 넣으면 돼요. 모델은 Nano Banana 2.1, 해상도 2k.

**① 소품 7개를 한 장에 (16:9) → 파일 이름 `props-sheet.png` → `props` 폴더에 넣기**
```

Every object fully separated and not touching, front view, detailed HD pixel art game props, no shadows, no text, no letters, no numbers.
```

**② 과학실 빈 벽 (1:1) → 파일 이름 `lab.png` → `bg` 폴더에 넣기**
```

두 장을 넣고 알려 주시면 제가 소품을 하나씩 잘라 배경을 투명하게 따서 게임에 넣어 드려요. 아래 장면별·소품별 프롬프트는 다른 장면까지 바꾸고 싶을 때 쓰면 돼요.

## 공통 규칙

- 인물은 게임 안의 픽셀 캐릭터를 그대로 쓰므로 **배경에는 사람을 넣지 않습니다.**
- 이미지 생성 AI는 한글 글자를 자주 틀리므로 **글자·간판·표지판도 넣지 않습니다.** (반 표지판, 칠판 글씨, 시계는 게임이 따로 그려요)
- 모든 프롬프트 끝에 아래 **공통 스타일 문장**을 붙이세요. 그래야 6장이 같은 그림체로 나와요.

```
detailed HD pixel art, 2D game background, Korean high school, soft natural light, warm cream walls with mint-green lower wall panels, clean and calm, no people, no characters, no text, no letters, no signs, no logos
```

- 추천 모델: **Nano Banana 2.1** (복도는 4:1 비율을 지원). 다른 장면은 **Soul Location**(배경 전용)도 좋아요.
- 해상도: 2k 이상

## 합성 단서 찾기 소품 (props 폴더)

단톡방 합성 영상과 합성 단서 찾기 과학실에 놓이는 물건들이에요. `침해금지편_실감판/props/` 폴더에 아래 이름으로 넣으세요.

**중요: 초록 배경으로 만들어 주세요.** 이미지 AI는 투명 배경을 잘 못 만들어요. 아래 문장을 프롬프트 끝에 붙여 초록 배경으로 만든 뒤 폴더에 넣고 알려 주시면, 제가 배경을 투명하게 따서 바꿔 드려요.

```
single object only, centered, front view, detailed HD pixel art game prop, isolated on a solid pure bright green background (#00FF00), no shadow on the background, no text, no letters, no numbers

## 넣는 방법

1. 힉스필드에서 위 프롬프트(+공통 스타일 문장)로 이미지를 만들고 내려받습니다.
2. 파일 이름을 표의 이름으로 바꿉니다. (png, jpg, webp 모두 됨)
3. `침해금지편_실감판/bg/` 폴더에 넣고 `index.html`을 새로 고침합니다.
4. 소품은 `props/` 폴더에 넣습니다.
5. 넣은 뒤 알려 주시면 제가 배경을 따고, 화면을 확인해 위치·밝기를 맞춰 드릴게요.
