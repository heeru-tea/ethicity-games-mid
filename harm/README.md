# AI 윤리 탐험대 1편 · 침해금지 — 37개의 알림 (실감판)

기본판(`침해금지편_완성본`)과 내용·규칙은 같고, 배경을 AI로 만든 그림으로 바꿀 수 있는 버전입니다.

- `bg/` 폴더에 정해진 이름의 배경 이미지를 넣으면 자동으로 적용됩니다. 없는 장면은 기본판 그림으로 보입니다.
- 이미지 프롬프트와 파일 이름은 `이미지_프롬프트.md`에 있습니다.
- 인물은 기본판과 같은 픽셀 캐릭터(`images/`)를 씁니다.
- 효과음: 알림·10초 초재기·단서 찾음·확산 경고·1교시 종 등. 파일 없이 브라우저에서 만듭니다. 오른쪽 위 **🔊 소리** 버튼으로 끌 수 있고, 그 기기에서 설정이 기억됩니다.
- 수업에는 **실감판만** GitHub에 올립니다.

## GitHub에 올릴 파일 (실감판)

게임이 실제로 쓰는 파일만 올리면 됩니다. 힉스필드 원본(png, 4~7MB)은 올리지 않아도 됩니다.

```
index.html
.nojekyll            (빈 파일, 아래 참고)
images/              캐릭터 8장 (png 전부)
bg/                  title.webp, street.webp, bedroom.webp, corridor.webp, lab-wall.webp, classroom-front.webp
                     (엔딩 배경을 넣었다면 ending-a, ending-b, ending-c 도)
props/               window.png, board.png, poster.png, clock.png, shelf.png, pot.png, hairpin.png
```

- 올리지 않아도 되는 파일: `bg/`의 `.png` 원본들, `props/props-sheet.png`, `props/lab.png`, 안내용 `.txt`, `이미지_프롬프트.md`
- `.nojekyll`은 내용 없는 빈 파일입니다. 메모장으로 빈 파일을 만들어 이름을 `.nojekyll`로 저장해 올리면 됩니다.
- 올리는 방법(Settings → Pages)은 기본판 README와 같습니다. 주소 예: `https://<아이디>.github.io/<저장소>/` (수업용), `…/?demo` (교사 데모)

## 학번·이름 입력과 PDF 보고서

- 시작할 때 학번(숫자 4~6자리), 이름, 닉네임을 입력합니다. 게임 대사에는 닉네임만 나오고, 학번·이름은 마지막 활동 보고서에만 들어갑니다.
- 사례 보고서를 쓰고 [생각 카드 만들기] → **[PDF로 저장]**을 누르면 인쇄 창이 열립니다. '대상'을 'PDF로 저장'으로 고르면 `침해금지_활동보고서_학번_이름.pdf`로 저장됩니다.
- 입력한 내용은 어디에도 전송되지 않습니다. (사례 보고서 내용만 그 기기 브라우저에 저장)

## 교사용 데모 모드

- 주소 끝에 `?demo`를 붙여 엽니다. 예: `https://<아이디>.github.io/<저장소>/?demo` 또는 내 컴퓨터에서 `index.html?demo`
- 왼쪽 아래 **🎬 교사 데모** 버튼으로 장면(1장 10초, 2장 알림·복도·휴대폰·단서·누구에게, 3장, 4장, 엔딩 A·B·C, 사례 탐구)으로 바로 이동합니다.
- '10초 반응 가정'(넘기기 / 공감 / 전달+공감+저장 / 지워 달라고 말하기)을 고르면 그 반응을 한 것으로 보고 다음 장면을 보여 줍니다.
- 데모 모드에서는 학번·이름 입력 없이 '교사 시연'으로 시작할 수 있고, 새로 고침 확인 창도 뜨지 않습니다.
- 수업 때 학생에게 나눠 주는 주소에는 `?demo`를 붙이지 마세요.
