# 블랙박스를 열어보는 고양이

중학생 대상 AI 투명성 교육 게임. 사건 다섯 개를 ‘궁금한 것 → 직접 확인 → 선택 → 결과 → 후속 조사 → 만든 사람이라면: 미리 알리기 → 생각 정리’ 일곱 화면으로 진행하고, 마지막에 ‘나의 조사 보고서’를 PDF로 저장합니다.

## 실행

- `index.html`을 브라우저로 열면 **시작 화면**이 먼저 나오고(2026-11-11), ‘게임 시작하기’(저장이 있으면 ‘이어하기’)를 누르면 게임으로 들어갑니다. (사건 4·5 새 그림 webp 사본은 `node tools/art-4-5.cjs`로 만든다. 아래 ‘에셋’.) 빌드와 설치가 필요 없습니다.
- `art.html`은 전체 에셋 보관함입니다.
- 안정적인 로컬 저장과 미리보기: 이 폴더에서 `node serve.cjs` 실행 후 `http://127.0.0.1:4178/`.
- `http://127.0.0.1:4178/?preview=s01`은 진행을 저장하지 않는 S01 미리보기입니다(시작 화면 없이 바로 사건 1).
- 파일로 실행할 때 브라우저가 저장을 차단하면 현재 창에서 플레이를 계속할 수 있으며, 화면 아래에 저장 제한을 알립니다.

## 구성 (2026-11 개선판)

- **배경음악(2026-11-12, `ui/bgm.js`)**: 곡 두 개(아래 ‘에셋’). 메인곡 = 시작 화면·프롤로그·궁금한 것·선택·결과·미리 알리기·생각 정리·마지막·보고서, 조사곡 = 직접 확인·후속 조사(사건 안에서 자료를 보고 판단하는 동안). 마무리 전용 곡은 사용자가 보류해서 마무리도 메인곡. 수첩·설정 창을 열어도 곡은 그대로(잠깐 볼 때마다 바뀌지 않게 — 화면 단계로만 정한다). 곡이 바뀌면 약 1초 겹쳐 넘기기, 반복 재생, 같은 곡이면 다시 시작하지 않음(돌아오면 멈춘 자리부터), 소리 크기 0.14. 탭을 숨기면 멈추고 돌아오면 이어서. 브라우저가 첫 누르기·키 입력 전에는 소리를 막으므로 그때 처음 곡을 받는다(`preload="none"`, 첫 화면 로딩을 막지 않음). 설정 창의 ‘배경음악’ 체크로 켜고 끈다(기본 켜짐) — 값은 진행 저장과 따로 `ethicity.transparency.settings.v1`(`{"bgm":false}`), 저장이 막히면 이 창에서만. 곡을 못 읽거나 재생이 막혀도 오류 없이 조용히 넘어간다. 움직임 줄이기와 상관없고, 인쇄·PDF에는 영향 없다.

- 시작 화면(2026-11-11 시안, `ui/title.js`·story.js `title`·style.css 맨 끝): 게임을 열 때마다 먼저 나온다. 제목(h1) · 도입 문장 · 무슨 게임인지 한 줄 · 한눈에 정보(사건 5개 · 판단 20개 · 마지막에 나의 조사 보고서 — 플레이 시간은 검증 전이라 적지 않음) · ‘게임 속 한 장면’(사진 사건의 판단 문장 하나와 세 갈래를 story에서 그대로 가져온 그림 구실, 누를 수 없음) · 버튼. 저장된 진행이 없으면 ‘게임 시작하기’ 하나, 있으면(프롤로그를 지나 본 저장) ‘이어하기’(으뜸, 아래에 ‘사건 2 · 글 검사 · 직접 확인부터’처럼 어디부터인지)와 ‘처음부터 하기’(기존 확인 창 → ‘지우고 처음부터’를 누르면 프롤로그로 들어간다). 버튼을 누르면 예전 첫 화면(프롤로그 또는 저장된 곳, 기존 ‘저장된 곳부터 이어서 해요’ 안내 그대로)으로 들어간다. 게임 안에서는 설정 창의 ‘시작 화면으로’로 돌아온다(머리줄의 게임 이름을 눌러도 새로 열려 시작 화면). **저장 형식은 그대로** — 시작 화면을 보고 있는지는 화면에만 쓰는 값 `S.title`. 시작 화면에서는 게임 메뉴(수첩·설정)를 숨긴다(`body:has(#app.at-title)`).
  - 대표 그림은 **기존 그림만** 겹친 것: 수리점 배경(`bg-repair-shop`) + 모아 전신(`moa-attentive`) + 소품 묶음의 검은 상자 셋(닫힌 것 둘·작은 창 하나). 세 그림을 SVG 하나(`viewBox` = 배경 그림 크기, `slice`)에 넣어 함께 늘고 함께 잘리게 했고, 설명은 그 SVG의 이름(role=img, aria-label) 하나에 모았다. 맞춤이 다른 두 벌(세로로 긴 배치 = 오른쪽 아래, 넓은 배치 = 오른쪽 가운데)을 그려 두고 CSS가 하나만 보인다. 상자·모아 발밑에 옅은 그림자(타원)를 깔았다. **container query 단위(cqw·cqh)는 쓰지 않는다** — 처음에 그렇게 맞췄더니, 시작 화면을 거친 뒤 휴대폰 게임 화면에서 세 구역을 다 눌렀을 때 화면이 29px 움직였다(flow-browser ‘scrollY 그대로’ 검사가 잡음, 규칙을 덩어리별로 빼 보며 원인 확인).
  - 배치: 넓은 화면(가로:세로 3:2 이상)은 그림이 화면 가득 + 왼쪽 골목 자리에 유리 판 하나 / 세로로 긴 화면은 위에 그림·아래에 판(너비 900 이상이면 두 칸) / 휴대폰 세로는 판이 그림 아래 붙은 종이이고 버튼은 화면 아래에 붙음 / 낮은 화면(가로로 누인 휴대폰)은 조작 안내 → 한 장면 → 한눈에 정보 → 도입 문장 순으로 뺀다. 연출은 판이 한 번 떠오르는 것 하나(0.36초, 움직임 줄이기면 없음).
  - 새로 그리면 더 좋아질 대표 그림의 지시서 초안: `docs/codex-art-brief-title.md`(맡길지는 사용자 결정).
- 사건마다 일곱 화면: 궁금한 것 → 직접 확인(누르고 찾기 + 판단 셋) → 선택 → 결과 → 후속 조사 → 미리 알리기 → 생각 정리. 장면 0 프롤로그, 1~7 사진, 8~14 글 검사, 15~21 얼굴 인식, 22~28 구청 캠프, 29~35 은하수 그림, 36 마지막, 37 보고서(engine `LAYOUT`에서 계산).
- 사건 4·5(2026-11-10 새로 짬, 정부 「AI 윤리기준」 7. 투명성 반영, 설계 `docs/2026-11-10-cases-4-5-rework-design.md`, 계획 `docs/2026-11-10-cases-4-5-rework-plan.md`). 옛 사건 4·5(도서관 추천·밤하늘 모임)는 버렸다. 문장 모두 교사 검수 대기.

  - **2026-11-12 저녁 후속 요청(위 줄과 다른 곳은 이 줄이 맞다)**: ① **사건 4·5 미리 알리기 = ‘잘못된 안내문 고치기’**(사건 1~3은 카드 고르기 그대로). 짧은 틀린 안내문(초안)을 칸마다 고른 문장으로 고친다 — 사건 4 구청 안내문 칸 넷(AI가 하는 일·담당 부서·재검토 방법은 빈 칸, 마지막 문장 “AI가 뽑으니 절대 차별이 없어요.”), 사건 5 냥스타 홍보문 칸 셋(AI로 만든 부분·실제 하늘 “토요일에 이 그림처럼 보일 거예요.”·덧붙일 것). 칸·맞는 선택지는 engine `noticeSlots`, 글은 story `notice.fix`·`D.notice.fix`. 자유 서술·자동 채점 없음, 모든 칸을 골라야 ‘고친 안내문 붙이기’, 붙이면 칸마다 ✓/! 태그와 한 줄, 판정은 ‘다시 볼 칸: …’, 한 번 붙이면 틀려도 다음으로(카드 고르기와 같은 원칙). 누르는 수: 칸 수 + 붙이기 한 번(사건 4 다섯 번, 사건 5 네 번 — 카드 고르기의 정답 경로 네~다섯 번과 비슷). 수첩·보고서는 ‘고친 안내문’과 최종 문장·다시 볼 칸·판정. 이 기능 전에 카드로 붙인 사건 4·5 안내문은 그대로 두고 ‘이전 방식으로 작성한 안내문’으로 보인다. 설계 `docs/2026-11-12-notice-variation-design.md`(구현 메모에 설계와 다른 점). ② 사건 4 판단 3을 마을별 결과의 새 칸(평균 참여·참여 점수, 점수 규칙은 표 아래 한 줄)으로 직접 확인되는 문장으로 바꾸고, 버스와 불참의 관계는 버스 쪽지를 열 때 모아의 물음으로만 남겼다. ③ 대사 없이 ‘자세히 보기’만 있던 모아 말 상자(사건 3 점원의 말, 사건 4 선발 기준표) → 화자 없는 펼침 ‘자료 설명’. ④ 마지막 자료를 찾아 첫 판단이 나와도 그 자료가 그대로 보인다(판단 카드의 ‘볼 자료’를 누르면 근거 자료로, ‘다음 말 보기’에서는 예전처럼 근거 자료로 바뀐다). ⑤ 사건 4 후속 조사는 달라진 두 줄(담당 부서·이의 신청)을 모두 눌러야 판단이 나온다(줄마다 저장). ⑥ 참고 사례의 개인정보 보호법 제37조의2 설명을 조문대로(완전히 자동화된 결정, 행정청의 자동적 처분 제외, 게임 속 구청에는 그대로 적용되지 않음). 문장 전부 아래 교사 검수 대기.
