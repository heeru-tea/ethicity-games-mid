# 블랙박스를 열어보는 고양이

중학생 대상 AI 투명성 교육 게임. 사건 세 개를 ‘궁금한 것 → 직접 확인 → 선택 → 결과’ 네 화면으로 진행합니다.

## 실행

- `index.html`을 브라우저로 열면 시작합니다. 빌드와 설치가 필요 없습니다.
- `art.html`은 전체 에셋 보관함입니다.
- 안정적인 로컬 저장과 미리보기: 이 폴더에서 `node serve.cjs` 실행 후 `http://127.0.0.1:4178/`.
- `http://127.0.0.1:4178/?preview=s01`은 진행을 저장하지 않는 S01 미리보기입니다.
- 파일로 실행할 때 브라우저가 저장을 차단하면 현재 창에서 플레이를 계속할 수 있으며, 화면 아래에 저장 제한을 알립니다.

## 구성 (2026-11 읽기 부담 개선판)

- 장면 번호 0~13 유지: 0 프롤로그, 1~4 사진, 5~8 글 검사, 9~12 얼굴 인식, 13 마지막. 사건마다 hook(궁금한 것) · check(직접 확인) · choose(선택) · result(결과).
- 직접 확인: 자료 버튼(원본 보기, AI의 자르기 기준 보기, AI 안내 보기, 작성 기록 보기, 알림 기록 보기, 점원의 말 보기, 얼굴 비교 사진 보기)을 누르고, 사진·기록 안에서 직접 찾는다(원본에서 담이 찾기, 세 구역 점수 열기, 표시된 문장 찾기, 알림과 다른 말 찾기). 내부 자료 번호(P1·W2 등)는 화면에 없다.
- 판단 하나: 사건마다 한 문장을 ‘자료로 확인돼 / 자료로는 알 수 없어 / 자료와 달라’ 중 하나로 고른다. 정답 반복 없이 한 번 고르면 짧은 피드백과 정리를 보여 준다. 고른 칸은 수첩에 그대로 남는다.
- 선택: 사진 2개(자동으로 자른 사진·모두 나오는 사진), 글 3개, 얼굴 3개. 선택 전 계획 설명은 없고, 고르면 결과 화면으로 간다. 결과는 그림에도 반영된다(게시판 사진 범위, 발표 표시, 입장 제한 표시와 점원 그림). ‘다른 선택 해 보기’로 바꿀 수 있고 처음 고른 것은 보존된다.
- 결과 화면 끝에 ‘아직 모르는 점’ 한 문장. 부연 설명은 ‘자세히 보기’.
- 수첩은 자동 기록(궁금한 것·확인한 것·내 판단·처음/마지막 선택·아직 모르는 점). 열어 보는 것은 선택.
- 도움 경로와 주장 네 개 판정, 사진 범위 슬라이더, 담이 중심 사진 선택은 이번 개선에서 뺐다.

## 저장·공통 연동

- `ethicity.player`: 닉네임 읽기만.
- `ethicity.transparency.progress.v1` (version 1, revision 4): 장면, 가장 멀리 간 장면, 확인한 자료, 사건별 판단, 처음/마지막 선택, 마지막 질문.
- 다시 열면 저장된 화면부터 이어지고 ‘처음부터 하기’ 안내가 한 번 보인다. 설정과 마지막 화면에서 ‘처음부터 다시 하기’(이 게임 키만 초기화).
- revision 3 이하 저장: 사건 단위로 이어 간다. 자료 번호는 새 자료로 옮기고, 지나간 사건의 판단은 ‘이전 판에서 판단함’으로 둔다. 사진 ‘직접 고르기’는 ‘모두 나오는 사진’으로, 없어진 ‘담이 중심’ 선택은 다시 고르게 한다. 손상된 저장은 프롤로그부터.
- 외부 전송·교사용 수집 없음.

## 에셋

내장 image_gen 도구로 제작했습니다. 생성 프롬프트와 규격은 `assets/s01/` 및 `assets/remaining/`의 JSON에 있습니다.

- 배경 4: 수리점, 게시판, 복도, 빵집.
- 인물 6명: 모아·루루·담이·밤이·올빼미 교사·곰 점원. 전신 PNG는 원고 루루와 재검토 점원을 포함해 8개.
- 모아 4표정 atlas + 기존 기본 포즈. 2×2 순서: 놀람, 의심, 집중, 안도.
- 소품 3×2 atlas: 닫힌 상자, 작은 창 상자, 수첩 / 편지, 원고, 예약표.
- 축제 원본과 가상 얼굴 비교 2개. 축제 원본에서 파생한 실제 crop PNG 2개.
- 총 PNG 18개(생성 원본 16, 파생 crop 2). 대사·문서·상태 표식·중심점은 코드로 표시합니다.
- 캐릭터 PNG의 투명 알파를 확인했습니다. 일부 가장자리 반투명 음영과 표정 시트 외곽 여백은 추가 아트 다듬기가 가능합니다.
