# 블랙박스를 열어보는 고양이

중학생 대상 AI 투명성 교육 게임. 일러스트와 대화, 자료 조사, 주장 대조, 조치 선택, 후일담으로 구성합니다.

## 실행

- `index.html`을 브라우저로 열면 시작합니다. 빌드와 설치가 필요 없습니다.
- `art.html`은 전체 에셋 보관함입니다.
- 안정적인 로컬 저장과 미리보기: 이 폴더에서 `node serve.cjs` 실행 후 `http://127.0.0.1:4178/`.
- `http://127.0.0.1:4178/?preview=s01`은 진행을 저장하지 않는 S01 미리보기입니다.
- 파일로 실행할 때 브라우저가 저장을 차단하면 현재 창에서 플레이를 계속할 수 있으며, 화면 아래에 저장 제한을 알립니다.

## 구현 범위

- S00~S13: 세 사건, 대화, 필수 단서 잠금, 재열람, 정오답 피드백, 도움, 조치 유지·수정, 후일담, 수첩, 마지막 추천 질문, 출처와 토론.
- 사진: 단일 원본을 canvas로 실제 자릅니다. P3 중심 (1200,250), 범위 (900,50,600,400), 가상 값 2·5·8. 직접 조절과 전체 보기 제공. 포함 검사는 다섯 친구의 얼굴 영역을 기준으로 합니다.
- 각 사건의 첫 조치와 최종 조치를 별도 저장합니다. 조치 재검토 시 마지막 확정 조치를 보존하고 새 선택을 확인한 뒤 바꿉니다.
- 도움 설명을 열 때부터 기록합니다. 도움 후 활동은 독립 확인으로 표시하지 않습니다.
- 글 원고와 얼굴 인식 사건의 불확실성은 남깁니다. 재검토 약속을 점검 완료로 표현하지 않습니다.
- 375px 이상 반응형 구성, 버튼 기반 배열, 키보드 범위 조절, 사진 확대, 초점 표시, 모달 초점 복귀.

## 저장·공통 연동

기존 `privacy/js/storage.js`에서 확인한 규약을 따릅니다.

- `ethicity.player`: 닉네임 읽기만. 쓰거나 삭제하지 않습니다. 공식 캐릭터 매핑은 현재 비어 있어 임의 매핑하지 않았습니다. 모아는 서사 속 주인공입니다.
- `ethicity.transparency.progress.v1`: 이 게임의 장면, 확인 자료, 활동, 도움, 선택, 자르기 범위만 저장합니다.
- 다른 게임과 공통 파일은 수정하지 않습니다. 완료 결과의 외부 수집·교사용 분석·네트워크 전송은 없습니다.
- 초기화는 게임 전용 키의 내용만 새 진행으로 바꿉니다.

## 에셋

내장 image_gen 도구로 제작했습니다. 생성 프롬프트와 규격은 `assets/s01/` 및 `assets/remaining/`의 JSON에 있습니다.

- 배경 4: 수리점, 게시판, 복도, 빵집.
- 인물 6명: 모아·루루·담이·밤이·올빼미 교사·곰 점원. 전신 PNG는 원고 루루와 재검토 점원을 포함해 8개.
- 모아 4표정 atlas + 기존 기본 포즈. 2×2 순서: 놀람, 의심, 집중, 안도.
- 소품 3×2 atlas: 닫힌 상자, 작은 창 상자, 수첩 / 편지, 원고, 예약표.
- 축제 원본과 가상 얼굴 비교 2개. 축제 원본에서 파생한 실제 crop PNG 2개.
- 총 PNG 18개(생성 원본 16, 파생 crop 2). 대사·문서·상태 표식·중심점은 코드로 표시합니다.
- 캐릭터 PNG의 투명 알파를 확인했습니다. 일부 가장자리 반투명 음영과 표정 시트 외곽 여백은 추가 아트 다듬기가 가능합니다.

## 검증

`node --test tests/engine.test.cjs tests/combinations.test.cjs`

헤드리스 Edge와 이 컴퓨터의 번들 Playwright로 실행:

- `node tests/preview.cjs`: S01 데스크톱·모바일 캡처.
- `node tests/browser-probe.cjs`: 꼼꼼한 학생, 출력을 그대로 믿는 학생, 도움 이용 학생의 세 경로. DOM 클릭 프로브이며 실제 학생 실험이 아닙니다. 저장 차단·손상, 외부 요청, 가로 넘침도 검사합니다.
- `node tests/review-regressions.cjs`: 실제 키보드 Enter/Escape/방향키 조작, 도움말 닫기, 저장 배열 복원.

스크린샷과 JSON 결과는 `tests/`에 있습니다. 샌드박스 임시 프로필 권한 문제로 브라우저 검증은 권한 조정 후 실행했습니다.

## 미검증

실제 학생 대상 교육 효과, 실제 15~20분 플레이 시간, 스크린리더 실사용, 다른 기기의 Safari/Firefox 동작은 검증하지 않았습니다. 공개 배포나 원격 push는 하지 않았습니다.
