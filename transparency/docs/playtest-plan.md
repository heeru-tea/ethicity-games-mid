# 플레이테스트 반영 계획

사용자가 제공한 P0/P1/P2 요청서를 구현 기준으로 삼는다. 기존 단일 HTML, engine.js 상태 전이, story.js 자료, app.js 렌더링 구조를 유지한다.

## 제약과 결정
- transparency 폴더 내부만 수정. 출처와 창작 고지 유지. 외부 요청 추가 금지.
- 현재 transparency 브랜치는 이미 분리된 worktree이며 작업 시작 시 변경 없음.
- v1 저장 키 유지. 추가 schema 표식으로 과거 첫 조치 기록을 최종 확정 값으로 보정한다. 과거 확정 이력은 복원 불가능함을 기록한다.
- 새 주장 판정은 기존 완료 과제를 보존하되, 새 주장 과제를 과거에 풀었다고 간주하지 않는다. 이전 장면에서 보충 가능하게 한다.
- 조치 선택은 계획, 예측, 확정, 결과 순서. 사진 범위 편집은 확정 뒤 실행 단계로 옮겨 실제 결과와 설명을 함께 보여준다.
- 모바일 수첩은 접이식 하단 시트, 데스크톱은 활동 아래 패널. 조작 영역을 가리지 않게 공간 확보.
