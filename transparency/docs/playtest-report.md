# 고양이 게임 플레이테스트 반영 보고

## 변경 범위

`transparency/` 내부만 수정했다. 배포와 원격 push는 수행하지 않았다.

| 구분 | 반영 내용 |
|---|---|
| P0 | 도움 수락 시점 기록, 처음 확정한 조치 보존, 사진 범위와 설명 일치, S11 선택지별 힌트, 남은 필수 활동 목록, 문제 제목 옆 배지, 프롤로그 라벨과 문구 정리 |
| P1 | S00 조사자 미션과 세 칸 판정 틀, 진행 중 일곱 칸 수첩, 사건 완료에 따른 상자 열림, 조치 계획·예측·확정·결과 순서, 중립적인 조치 이름 |
| P2 | 사건마다 주장 네 개, 근거 선택과 세 종류 도장, 알 수 없음 판정, 판정별 수첩 자동 기록, 두 번 오답 도움 강조, S02 오버레이 숫자 지연 표시, S13 현실적인 오답 |

S06의 작성 과정과 S10의 사건 흐름은 조사 자료로 읽고 확인한다. 핵심 대조 활동은 S03·S07·S11의 같은 주장 판정 형식으로 통일했다. 드래그 대신 모든 근거와 도장을 버튼으로 제공한다.

수동 사진 조정은 조치를 확정한 뒤 실행한다. 이때 처음 확정 기록은 남지만, 다섯 얼굴을 모두 포함하기 전에는 다음 장면으로 갈 수 없다. 사진 설명·담이 반응·수첩 후일담 모두 실제 범위 상태에 맞춘다.

## 저장 호환성

- 저장 키 `ethicity.transparency.progress.v1`과 version 1 유지. 내부 revision 3, claims, attempts 추가.
- 기존 장면, 읽은 자료, 활동 기록, 최종 확정 조치 보존.
- 과거 첫 확정 순서는 기록되지 않았으므로 복원 불가. 이전 최종 확정값으로 보정하고 수첩에 한계 표시.
- 이전 도움 기록은 열기와 수락을 구분할 수 없어 보존. 새 진행부터 수락 시점만 기록.
- 새 주장 판정을 이미 풀었다고 간주하지 않음. 기존 엔딩에서도 남은 장면으로 이동해 보충 가능.
- 저장 내용이 손상되면 S00에서 안전하게 시작.

## 변경 파일

- `app.js`: 화면 흐름, 미션, 수첩, 조치, 상태에 맞는 설명, 도움·포커스 처리.
- `engine.js`: 첫 확정·최종 확정, 도움·판정 기록, 진행 조건, 기존 저장 복원.
- `claims.js` (신규): 주장 12개, 정답 근거·도장, 선택별 피드백.
- `story.js`: 표현 통일, 조치 이름과 계획, 조사 장면 문구.
- `index.html`: 로컬 주장 데이터 스크립트 로드.
- `style.css`: 수첩·도장·미션·진행 상자, 모바일 배치, 동작 줄이기.
- `README.md`, `docs/playtest-plan.md`, `docs/playtest-report.md`: 사용·호환성·검증 기록.
- `tests/engine.test.cjs`, `tests/combinations.test.cjs`, `tests/playtest.test.cjs`: 상태 전이 회귀 테스트.
- `tests/playtest-browser.cjs`, `tests/browser-probe.cjs`, `tests/review-regressions.cjs`, `tests/visual-probe.cjs`: 브라우저 경로와 화면 검증.
- `tests/playtest-results.json`, `tests/playtest-*.png`: 검증 출력과 화면 캡처.

## 확인 방식과 미확인 항목

자동 검증은 로컬 헤드리스 Edge에서 DOM 클릭 및 일부 실제 키보드 Enter·Escape·방향키를 사용한다. 학생이 직접 플레이한 결과와 구분한다. 실제 학생의 이해도·긴장감·소요 시간, 스크린리더 실사용, Safari·Firefox 및 실제 휴대폰은 확인하지 않았다. NIST·Twitter·Vanderbilt·FTC/Rite Aid 출처 설명과 창작 고지의 의미를 유지했다.

## 최종 검증 결과

- `node --test transparency/tests/*.test.cjs`: 16개 통과. 27개 최종 조치 조합 포함.
- `node transparency/tests/playtest-browser.cjs`: 꼼꼼한 경로(1280×800), 다른 조치 경로(390×844), 도움 경로(390×844) 모두 S00부터 S13 완료 및 새로고침 후 완료 유지.
- 모든 도움 가능 장면에서 열고 닫기 또는 Esc 후 직접 풀이가 independent로 기록. 독립 경로의 엔딩 도움 이용은 세 사건 모두 이용하지 않음.
- 아홉 조치의 예측·확정 검사, 세 사건의 미확정 취소·첫 확정·최종 확정·진행 중 새로고침 통과. 확정 전 새 결과·반응은 표시하지 않음.
- 수동 조정 전후 설명, 다섯 얼굴 포함 후 반응, 조정 전 수첩 후일담 확인.
- 오답 118개: 각 선택의 피드백 출력과 미완료 상태 유지. 두 번 오답 도움 강조 확인.
- 기존 v1 S07 복원과 새 주장 풀이 후 진행, 손상 세이브의 S00 복구, 저장 차단 시 현재 창 플레이 확인.
- Enter 근거·도장 선택, 정답 후 포커스 유지, Escape 모달 복귀, 방향키 연속 범위 조절 확인.
- 1280×800 / 390×844의 모든 진행 장면 가로 넘침 없음. 수첩을 펼쳐도 활동 영역과 겹치지 않음. S00 미션은 첫 뷰포트 안에 있음.
- 각 전체 경로에서 페이지 JavaScript 오류 0개, 외부 요청 0개.
- 스크린샷 확인: 모바일 S00, 모바일 S07 주장·수첩, 데스크톱 S04 및 수첩. 나머지 장면의 배치 조건은 프로브로 확인.
- 출처 설명 함수는 P0 커밋과 문자열 비교로 동일함을 확인.

검증 중 샌드박스의 Edge 실행 제한과 일부 이미지 로딩 시간 초과가 있었다. 브라우저 실행 권한을 조정하고, 상태 검증의 문서 준비 대기와 캡처의 이미지 로딩 검사를 분리한 뒤 최종 명령이 종료 코드 0으로 완료됐다.

별도 읽기 전용 리뷰에서 발견한 수동 조정 전 후일담과 비활성 fieldset 포커스 복원 문제를 수정하고 브라우저 회귀 검증으로 확인했다. 기존 helped 조치의 재선택 취소 기록 보존도 엔진 회귀 테스트로 확인했다.
