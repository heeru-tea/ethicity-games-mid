# 학교 외관과 문 에셋

기존 학교 앞이 잔디에 떠 보이는 문제를 줄이기 위한 외관·포장 광장과, 실내 교실·도서관용 문을 제작했다.

- 외관 1종 + 포장 광장 1종 + 교실/도서관 문 열린 상태·닫힌 상태 각 2종 = PNG 6종.
- 기존 학교 외관 및 게임 코드는 변경하지 않았다. 연결 작업은 CLAUDE_HANDOFF.md 참조.
- preview.html / preview.png: 소재 미리보기. 실제 게임 화면이 아니다.
- asset-metadata.json: 이미지 원본 크기, 알파 경계, 완전 투명 픽셀 수. check-preview.cjs로 로딩·투명 배경을 검증하고 갱신한다.
- 열린 문은 닫힌 문 이미지를 기준으로 다시 제작해 프레임 디자인을 맞췄다. 생성 이미지이므로 정밀한 프레임 좌표 일치를 보장하지 않으며, 게임 적용 시 문턱과 프레임 기준 정렬을 확인한다.
- 로컬 에셋 납품이며 원격 push·배포는 하지 않았다.

## 2026-10-18 실내 문 연결 완료
- school.js: 교실 (8,7), 도서관 (15,7)에 새 열린/닫힌 문 4장 연결. 각 알파 경계를 잘라 공통 문턱 기준으로 배치. 높이 교실 1.72칸 / 도서관 1.63칸.
- map.js: 문을 캐릭터와 같은 깊이 정렬 목록에서 그린다. 열린 문 아래에는 복도 바닥만 표시한다.
- 거리 1.6칸 이내 열림 / 2.1칸 이상 닫힘으로 깜빡임 방지. 충돌/통행 데이터는 수정하지 않음.
- check-school-doors.cjs: 격리 Edge에서 4장 로딩, 양방향 실제 키보드 통과, 상태 전환/경계 유지, PC·모바일 캡처, pageerror 0. 도서관 앞 NPC는 검증 페이지에서만 옆으로 옮겨 통로를 확보했다. 저장 위치의 for 필드는 유지해야 함.
- 외관·forecourt와 학교 현관문은 이번 실내 문 교체 범위에 포함하지 않음. 미배포.
