# 학교 진입부·실내 문 에셋 적용 지시

2026-10-18. 이번 작업은 **에셋 납품**이다. 이 폴더의 PNG를 아직 게임에 연결하지 않았다. 기존 assets/school/exterior.png는 보존했다. 최신 git diff와 privacy/CLAUDE.md부터 확인하고 다른 에이전트의 변경을 유지할 것.

## 파일

- exterior-v2.png: 기존 학교의 지붕·시계·창·중앙 현관을 유지하며 낮은 기단, 입구 계단·랜딩, 화단을 보강한 외관.
- forecourt.png: 학교 앞 포장 광장과 중앙 보행로 연결부. 건물과 별도 레이어로 제공한다.
- door-classroom-closed.png / door-classroom-open.png: 교실 미닫이문 두 상태.
- door-library-closed.png / door-library-open.png: 도서관 문 두 상태.

## 외관과 진입부

1. school.js의 외관 로더를 새 이미지로 연결한다. 단순히 기존 파일만 덮어쓰지 말고 계단 아래 기준점·현관 위치를 확인해서 그리기 위치를 정한다. 새 알파 경계를 기존 22×11 박스에 무조건 늘리면 건물이 눌리거나 실제 입장 위치와 어긋날 수 있다.
2. world.js 기준 학교 범위는 x=0..21,y=0..10, 현관 통행 칸은 (10,10),(11,10), 접근 길은 x=10..11,y=11..16이다. 착수 시 최신 코드가 달라졌는지 재확인한다. 원칙적으로 기존 문·지붕 전환 좌표는 유지한다.
3. 실제 현관 그림 → 계단 → 랜딩 → 포장 광장 → 교문 길이 연속되게 맞춘다. **포장 광장은 지붕이 걷혀도 남아 있어야 한다.** 외관과 함께 숨기지 않는다.
4. forecourt는 지형 위·건물/가구/사람 아래에 그린다. 그림 경계 밖은 기존 잔디와 이어진다. 새 포장이 기존 매점·진입로를 시각적으로 덮지 않도록 실제 배치를 확인한다. 광장과 보행로가 서로 이어지는 지점에 풀밭 띠를 남기지 않는다.
5. 기단과 접지 그림자는 건물 하단에만 있어야 한다. 광장 전체에 두꺼운 그림자나 검은 테두리를 만들지 않는다. 화단은 통로 옆에 두고 현관을 막지 않는다.
6. 장면용 그림의 경사로/계단이 실제 사용 가능한 진입로처럼 보이면 통행 영역도 맞춰야 한다. decorative 이미지와 충돌 데이터를 혼동하지 않는다.

## 실내 문

1. 기존 school.js의 ch==='d' 사각형 도형 문을 교체한다. 교실은 (8,7), 도서관은 (15,7)이다. 이 두 문만 대상으로 하고 학교 현관과 집 문은 임의로 바꾸지 않는다.
2. 문은 1칸 통로이지만 그림 높이는 약 1.5~1.7칸이 적합하다. 문틀 폭 약 1.0~1.15칸으로 시작한다. 정사각형 1×1칸으로 찌그러뜨리지 않는다. 문턱을 통행 칸 하단에 정렬하고 가구/캐릭터와 앞뒤 순서를 확인한다.
3. 열린/닫힌 PNG는 생성된 별도 이미지이므로 동일 프레임 시트로 간주하지 않는다. 두 파일의 알파 경계·문틀 폭·문턱 위치를 각각 측정하고 **같은 월드 기준점과 같은 문틀 크기**에 맞춰 상태 전환 시 튀지 않게 한다.
4. 플레이어가 접근하거나 통과 중이면 열린 상태, 충분히 멀어지면 닫힌 상태로 표현한다. 문은 기존대로 걸어서 통과할 수 있으며 별도 클릭·열쇠·막는 충돌을 추가하지 않는다. 근접 판정에 여유를 주어 경계에서 열림/닫힘이 깜빡이지 않게 한다.
5. 열린 문 중앙은 통로 바닥이 보여야 한다. 기존 도형 문을 먼저 그린 다음 열린 PNG를 얹으면 중앙에 가짜 문이 남는다. d 칸 바탕을 적절한 실내 바닥으로 그리고 PNG를 얹는다. 검은 구멍처럼 표현하지 않는다.
6. 교실명·도서관 표기는 기존 코드 텍스트를 유지한다. PNG에 이름이나 긴 글자를 새로 합성하지 않는다.

## 파일 처리와 검증

- 원본 PNG는 유지하고 알파 경계를 source crop하여 사용한다. 새 소재에 palette.js를 다시 적용하지 않는다.
- preview.html은 소재 확인용이며 게임 화면이 아니다. asset-metadata.json에 원본 크기와 알파 경계가 있다. 이 수치는 자동 측정한 바운딩 박스이지 문턱·문틀의 의미 좌표는 아니다.
- 학교 외부/현관 앞/내부/교실 문/도서관 문을 PC와 모바일에서 캡처한다. 현관 진입·퇴장 시 지붕만 전환되고 포장이 남는지 확인한다.
- 양방향 문 통과, 열린 문 중앙의 바닥, 캐릭터 겹침, 문 상태 전환 시 위치 변화와 깜빡임을 확인한다.
- 기존 저장 이어 하기와 모든 본편 목적지 길찾기 유지. 다른 게임 저장 데이터는 변경하지 않는다.
- 구현 완료 보고에서 실제 게임 연결 여부와 확인/미확인을 구분한다. 원격 push·배포는 요청 전 하지 않는다.
