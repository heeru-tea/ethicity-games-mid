# 실제 게임 연결

2026-10-18. `js/map.js`에서 `walk-boy/girl/hayun/seoa/dohyun/minjun/teacher.png` 7종을 실제 맵과 사건 무대에 연결했다. 이 문서는 이전 납품 문서의 '게임 미연결' 상태를 대체한다.

- 원본1024×1536을4×4로 크롭하고 기존48px 월드 단위를 유지한다. 원본 해상도가 맵 확대율을 바꾸지 않는다.
- 새 시트에는 기존 채도 보정을 중복 적용하지 않고 캐릭터를 그릴 때만 축소 보간을 켠다.
- 신규 이미지 로드 실패·잘못된 종횡비는 기존 `assets/sprites/` 시트로 복구한다. 주인공 선택 변경 중 이전 로드가 늦게 도착해도 현재 캐릭터를 덮어쓰지 않는다.
- `js/sprite-dom.js`는 관계 화면의 얼굴에 새 반신 초상화를, 전신에는 걷기 시트를 사용한다. 새 이미지 실패→기존 시트→이니셜 순서로 복구한다.
- 기존 맵 대화의 `assets/portraits/` 연결, 잠든 민준 전용 포즈와 일반 friend 캐릭터는 유지한다. 기존 NPC는 정지 상태이며 시트 연결만으로 자율 이동을 추가하지 않는다.
- 저장 규격·스토리·다른 게임은 변경하지 않았다. 커밋·push·배포하지 않았다.

검증 실행: 저장소 루트에서 PLAYWRIGHT_PATH를 Playwright 패키지 위치로 설정하고 `node privacy/tests/check-character-integration.cjs`. 이 검사는 격리된 브라우저를 사용하며 실제 사용자 저장소를 건드리지 않는다. 에셋 자체의 미세한 반투명 경계 경고는 WALK_DELIVERY.md 참고.

실행 결과: PC·모바일 실제 게임의 키보드 이동·남녀 전환·새 시트 크롭과 표시 배율, DOM 초상화, 신규 이미지 누락 시 맵/DOM의 기존 이미지 복구 통과. 기존 opening·stage-mode·stage-resize·map-resume·portrait·chapter-face 프로브37항목 통과, 오류0. PC·모바일 합성 스크린샷 육안 확인. 전체 엔딩 경로 전수 재검사는 이번 에셋 연결 작업에서 실행하지 않았다.
