## 이미지 및 연결 원칙

- 모든 PNG는 배경까지 완성된 불투명 16:9 장면이다. 투명 캐릭터 컷아웃, 타일, 맵 텍스처가 아니다.
- 남녀 버전은 같은 사건 단계의 대체 이미지다. 교실 반응과 교사 지원은 성별과 관계없이 공용이며, 보이는 플레이어의 얼굴·신체·실루엣을 넣지 않는다.
- `clash`는 서로 옷과 팔을 붙잡고 밀치는 비유혈 몸싸움이다. 승패나 전투 보상 장면이 아니며, 상처·피·고어는 묘사하지 않는다.
- 대사, 자막, 선택지, 이름표, 촬영 화면 문구 등 텍스트는 이미지에 굽지 않고 별도 HTML UI로 구현한다.
- 미리보기는 실제 DOM `<img>`를 사용하며 16:9 프레임과 `object-fit: contain`으로 원본 전체를 보여준다. 배경은 단색 불투명이고 체크무늬를 사용하지 않는다.
- 게임 연결 시에도 인물·배경이 잘리지 않도록 전체 장면을 보존한다. 이 납품은 기존 게임 코드나 사건 흐름을 수정하지 않는다.

## 미리보기와 검증

10개 PNG가 모두 준비된 뒤 저장소 루트에서 실행한다. 기존 `characters-v3/check-friends.cjs`와 동일하게 `PLAYWRIGHT_PATH`가 지정되어 있으면 해당 Playwright 모듈을 사용하고, 없으면 `playwright`를 사용한다. Microsoft Edge가 설치되어 있어야 한다.

```powershell
node privacy/assets/nightfox-event/check-preview.cjs
```

검증기는 `../../tests/serve.mjs`로 임시 로컬 서버를 열고, 개인 브라우저 프로필을 사용하지 않는 격리된 헤드리스 Edge 컨텍스트로 검사한다. 출력은 이 폴더에만 저장한다.

- `preview.png`: 10장 전체 컨택트 시트 스크린샷.
- `asset-metadata.json`: 파일별 로딩 오류, 원본 너비·높이, 비율, 투명 픽셀 수, DOM 표시 상태 및 브라우저 오류.
- `window.assetChecks`: 미리보기 페이지가 수집하는 파일별 검사 결과 배열. `window.assetChecksReady`가 `true`이면 10장의 검사가 끝난 상태다.

16:9 검사는 원본 높이 기준 최대 1픽셀 반올림 오차를 허용한다. 불투명도는 원본 전체 픽셀의 알파가 255인지 검사한다. HTTP로 열어야 캔버스 픽셀 검사가 가능하며, `file://`에서는 브라우저 보안 때문에 픽셀 검사 오류가 날 수 있다.

자동 검사는 서사 일치, 인물 동일성, 공통 시점에서 플레이어가 보이지 않는지, 그림 속 문자나 폭력 묘사의 유무를 판단하지 않는다. 이 항목들은 스크린샷과 원본을 육안 검수해야 한다. **2026-10-18 검증 완료:** 격리된 헤드리스 Edge에서 10장 모두 로딩 성공, 원본 1672×941(16:9 반올림 오차 내), 투명 픽셀 0, 브라우저 오류 0. 전체 미리보기와 주요 장면 원본을 육안 확인했다. 본편 연결 검증은 아직 하지 않았다.

## Claude Code 연결 지시

1. 기존 사건 8의 nightfox 도발과 현장 도착 분기를 확인한 뒤 해당 장면에서만 이벤트 CG를 연다. 다른 사건의 맵 배경을 교체하지 않는다.
2. 기존 주인공 선택값에 맞춰 `boy-` / `girl-` 네 장면을 선택한다. 도착 → 대치 → 몸싸움(해당 선택만) → 촬영 → 교실 반응 → 지원 요청 시 상담 순서를 기본으로 한다.
3. 현장에서 떠나거나 도움을 구한 경우 몸싸움·촬영 장면을 무조건 재생하지 않는다. 실제 분기 플래그에 따라 노출한다.
4. 대사는 HTML 텍스트로 별도 표시하고, 클릭·키보드로 다음 장면으로 넘긴다. 자동 진행이나 화면 깜빡임을 필수로 하지 않는다.
5. 모바일은 원본 비율을 보존하고 대사창을 그림 아래 배치한다. 화면을 채우려고 얼굴을 잘라내는 강제 cover는 피한다.
6. 촬영 피해 자체를 호감도 감점으로 처리하지 않는다. 친구 반응은 오해·걱정·거리감으로 구분하고, 싸움 선택과 무단 촬영·유포의 책임을 별도로 다룬다. 도움 요청은 회복 기회로 반영한다.
7. 모든 경로는 기존 사건 9로 복귀하게 하고, 기존 완료 결과 형식은 유지한다. 현재 엔딩 조건이 현장 방문만으로 D를 고정하는지 확인하여 수습 선택이 실제로 의미 있도록 조정한다.

PNG 파일 추가만으로 본편에 자동 표시되지는 않는다. 이 폴더의 이미지를 장면 분기와 연결하는 작업이 별도로 필요하다.
