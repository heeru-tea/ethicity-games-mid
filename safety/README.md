# 의료 AI 안전기준 위원회 — 안전성 탐험 게임 (`/safety/`)

중·고등학생이 미래종합병원의 **청소년 시민위원**이 되어 병원을 걸어 다니며, AI 진료 보조 시스템 ‘메디AI’를 어디까지 믿을지 정하는 탐험형 윤리 게임입니다. 고정된 가상 환자 100명에게 자신이 정한 기준을 적용해 결과를 확인하고, 새로운 오류 정보를 보고 기준을 다시 검토한 뒤, 나만의 **의료 AI 안전 운영 프로토콜**을 완성합니다.

> 핵심 질문: 의료 AI를 어디까지 신뢰해야 할까?

- 대상: 중·고등학생 / 개인 플레이 후 교실 토론 / 약 15~18분(목표치, 실측 전)
- 흐름: 시작(주의·주인공) → 프롤로그(로비에서 세 사람의 입장 → 회의실에서 임명·첫 판단) → 미션 1(운영실, 위험도별 AI 활용 기준) → 미션 2(로비 현황판에서 환자 100명 운영 재생 → 진찰실에서 사건 A·B·C) → 미션 3(운영실, 확신도 96% 오류 보고서 → 기준 유지·수정) → 미션 4(회의실, 예산 5P·오류 대응·책임 체계 → 최종 운영) → 프로토콜 → 엔딩 경향·성찰(글쓰기)·선택 경로
- 정답·오답 표시, 점수, 실패가 없습니다. 지표는 진료 지연·놓친 위험·검토 업무 세 가지를 따로 보여 주고, 엔딩은 경향(신속·철저·균형)일 뿐입니다.
- 안내 로봇은 정답을 말하지 않고 질문·단서·길 안내만 합니다.
- 서버·로그인·외부 API·분석 도구 없음. 병원·환자·AI·수치는 모두 허구입니다.
- 기획 정본: `docs/game-brief.md`(레포에는 올리지 않음).

## 실행

정적 파일입니다. `../shared/ethicity-elementary-common-v1/` 공통 팩을 함께 불러오므로 저장소 구조 그대로 엽니다.

```bash
node safety/tests/serve.mjs 8080      # → http://127.0.0.1:8080/safety/
```

`index.html`을 파일로 직접 열어도(`file://`) 동작합니다(ES 모듈·fetch를 쓰지 않음).

## 조작

- 걷기: 방향키·WASD, 또는 바닥을 누르면 그곳까지 길을 찾아 걷습니다. 사람·물건을 누르면 다가가서 말을 겁니다.
- 말 걸기·살펴보기: Space 또는 화면의 버튼. 선택지는 숫자 키 1~4로도 고릅니다.
- 상단: 길 안내(목적지까지 자동으로 걷기) · 로봇에게 묻기(단계별 질문) · 메뉴(대사 속도, 움직임 줄이기, 효과음, 처음 화면, 기록 지우기). Esc로도 메뉴를 엽니다.
- 760px 이하·세로 화면에서는 대화창이 무대 아래로 내려갑니다. 키보드 없이 터치만으로 끝까지 할 수 있습니다.

## 운영 시뮬레이션 (`js/patients.js`, `js/sim.js`)

- 환자 100명(경증 70·중증 20·응급 10)은 고정 데이터입니다. AI가 중증을 경증으로 본 7명, 경증을 중증으로 본 8명, 오래 기다리면 상태가 나빠지는 3명이 섞여 있습니다. 미션 3의 확신도 96% 오류(P047)는 처음부터 데이터에 들어 있습니다.
- 의사 3명이 오전 9시부터 4시간 동안 접수 순서·우선순위대로 봅니다. 기준은 AI가 붙인 등급에 적용됩니다(의료진은 실제 상태를 미리 모름). 같은 기준이면 결과가 늘 같습니다(난수 없음).
- 응급환자 평가는 어떤 기준에서도 즉시 이뤄집니다. 응급 시 AI 역할(알림·요약·감시)은 각각 다른 환자에게 작용합니다.
- 안전장치는 점수를 더하지 않고 특정 환자와 절차에 작용합니다(오류 집중 분석 → 같은 유형 오류, 추가 인력 → 재검토 전담, 불확실성 경고 → 재확인 대상 확대, 교육 → 알아채기 어려운 사례).
- 처리 시간·판정 기준은 `sim.js`의 `T` 한곳에 있습니다. 바꾼 뒤에는 `tests/sim.test.mjs`로 “모든 지표에서 이기는 기준이 없다” 등을 다시 확인합니다.

## 공통 팩 사용

| 용도 | 공통 ID |
|---|---|
| 주인공 | `jiho` · `haneul` · `saebom` · `onyu` · `daon` 중 선택(축척 0.82) |
| 안내 로봇 | `robot`(축척 0.65) — 메디AI가 아니라 위원회 안내 로봇 |
| 배경 | `ai_lab` → 메디AI 운영실, `nurse` → 진찰실 |
| 아이콘·효과음 | `map` `robot` `settings` `clue` `timer` `warning` `inspect` / `tap` `door` `paper` `collect` `win` |
| UI | `.ee-theme` `.ee-panel` `.ee-speech` `.ee-speaker` `.ee-button` `.ee-choice` `.ee-badge` `.ee-notice` `.ee-success` `.ee-icon` |

이동 영역·충돌·출입구·인물 위치는 이 게임이 장면마다 정했습니다(`js/config.js`의 `ROOMS`). 공통 팩의 예제 `walkAreas`는 쓰지 않습니다.

## 게임 전용 그림 (`assets/art/`)

병원 로비·위원회 회의실 배경, 운영 책임자·의료진 대표·환자 대표(서 있는 모습 + 표정 4종), 대기 환자 3명. 공통 팩 그림을 화풍 기준으로 fal.ai(nano-banana)에서 만들고 공통 팩 규격(배경 1672×941, 인물 96×128·발 48,120, 표정 1024×256)으로 맞춥니다.

```bash
# safety/.env 에 FAL_KEY=... (커밋 금지)
node safety/tools/art.mjs                 # 전부 생성 + 규격 맞춤(요금 발생)
node safety/tools/art.mjs director        # 하나만
node safety/tools/art.mjs --pack          # 받아 둔 원본(assets/art/raw, 커밋 안 함)으로 규격 맞춤만
```

그림이 없으면 같은 자리에 임시 도형을 그려 게임은 그대로 진행됩니다. 새 배경을 만들면 `config.js`의 로비·회의실 `walk`·`block`·`objects` 좌표를 그림에 맞춰 조정해야 합니다.

## 저장과 통합

| 키 | 내용 |
|---|---|
| `ethicity.player` | 공통 플레이어 정보 — 읽기만(주인공 미리 선택) |
| `ethicity.safety.progress.v1` | 단계·선택값(기획 6-3 상태값)·성찰 글 — 이어 하기용, 이 기기에만 |
| `ethicity.safety.settings.v1` | 대사 속도·움직임 줄이기·효과음 |
| `ethicity.result.safety` | 완료 기록 `{ completed, tendency, at }` — 성찰 글·개인정보 없음 |

통합 이벤트는 부모 창(`postMessage`)과 `window`(`CustomEvent`)에 함께 보냅니다: `ethicity:ready`(그림 로드 후) · `ethicity:progress`(`total: 6`, 프롤로그·미션 1~4·엔딩) · `ethicity:complete`(`result: { completed: true }`).

## 결과물 저장

프로토콜 화면과 엔딩에서 **인쇄하기**(프로토콜만 인쇄)와 **이미지로 저장**(1080px PNG, 글자·도형만 그려 `file://`에서도 동작)을 제공합니다. 성찰을 마친 뒤에는 성찰 글도 함께 들어갑니다.

## 검증

```bash
node safety/tests/sim.test.mjs                                        # 시뮬레이션: 구성·결정성·응급 즉시 평가·우위 정책 없음·사건·경향
PLAYWRIGHT_MODULE=<playwright 경로> node safety/tests/playthrough-browser.mjs   # 처음부터 끝까지(길 안내로 이동), 이어 하기, 이미지·인쇄, 완료 이벤트, 760·430px
```

`CHANNEL=msedge`로 설치된 Edge를, `SHOTS=<폴더>`로 화면 캡처를 남길 수 있습니다.
