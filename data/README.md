# 데이터 러너: 끊어진 도시 — 첫 버전(튜토리얼 + 1 임무)

AI 학습 데이터를 직접 골라 모으며, 데이터를 "목적에 맞게" 관리하는 책임을 경험하는 3레인 러너.
기획: `data-runner-plan.md` · 제작 설계: `docs/specs/2026-10-27-data-runner-v1-design.md`

## 여는 법
1. 이 저장소의 **`data` 브랜치**를 받는다.
2. `data/index.html`을 **더블클릭**(인터넷·서버 필요 없음). Edge·Chrome 권장.

## 조작
| | 키보드 | 터치 |
|---|---|---|
| 레인 이동 | ← / → (A / D) | 좌우로 밀기 |
| 카드 잡기 | Space | 화면 톡 |

카드는 닿기만 해선 안 들어간다. 빛나는 동안 잡기를 눌러야 가방에 담긴다. 오른쪽 위 ♪ = 소리 끄기.

## 흐름
타이틀 → 러너 프로필·독백 → 튜토리얼(개·고양이, 약 1분) → 1 임무 대화 → 브리핑 → 달리기(1분 30초) → 검수("?" 카드에 설명표 붙이기) → 감독관 → 결과 → (실패 시) 보충 달리기 → 선배 → 마무리

## 바로 들어가기(시험·조정용)
- `index.html?start=m1` — 튜토리얼 건너뛰고 1 임무부터
- `index.html?run=m1` / `?run=tutorial` — 달리기만(손맛 조정)

## 고치는 곳
- 손맛 수치(속도·판정 구간·퍼펙트 폭·가방 비울 칸 등): `js/config.js`
- 장면·필요한 조합·카드 수·대사: `missions/m1.js`, `missions/tutorial.js`, 인물 이름·색: `missions/cast.js`

결과는 실제 AI가 아니라 **단순화한 규칙**으로 만든 것이다(게임 끝에도 안내).
