# 데이터 러너: 끊어진 도시 — 튜토리얼 + 1 임무 + 2 임무

AI 학습 데이터를 직접 골라 모으며, 데이터를 "목적에 맞게" 관리하는 책임을 경험하는 3레인 러너.
기획: `data-runner-plan.md` · 제작 설계: `docs/specs/2026-10-27-data-runner-v1-design.md` · 가짜 카드 + 2 임무: `docs/specs/2026-10-28-data-runner-fakes-m2-design.md`

## 여는 법
1. 이 저장소의 **`data` 브랜치**를 받는다.
2. `data/index.html`을 **더블클릭**(인터넷·서버 필요 없음). Edge·Chrome 권장.

## 조작
| | 키보드 | 터치 |
|---|---|---|
| 레인 이동 | ← / → (A / D) | 좌우로 밀기 |
| 카드 잡기 | Space | 화면 톡 |

카드는 닿기만 해선 안 들어간다. 빛나는 동안 잡기를 눌러야 가방에 담긴다. 오른쪽 위 ♪ = 소리 끄기.

## 흐름
타이틀 → 러너 프로필·독백 → 튜토리얼(개·고양이, 약 1분) → 1 임무 → 2 임무

- **1 임무 「분실물 센터 AI」**: 대화 → 브리핑 → 달리기(1분 30초) → 검수 → 감독관 → 접수대 컨베이어 → 결과 → 보충 → 마무리. 이름표가 다 맞아도 자료에 빠진 모습(접힌 우산, 열린 지갑, 뒤집힌 스마트폰)이 있으면 그 물건만 분류 보류로 남는다.
- **2 임무 「분리배출 분류 AI」**: 대화 → 브리핑 → 달리기 → 검수(**그림과 이름표가 안 맞는 카드의 이름표 고치기**) → 감독관 → **컨베이어 실제 분류**(처음 보는 물건 14개를 우리 AI가 분류함에 넣는 모습, 건전지가 엉뚱한 함으로 가면 비상 정지, 2배속·건너뛰기) → 장면별 결과 → (실패 시) 보충 → 선배 → 마무리

**가짜 카드**(1 임무부터): 그림과 이름표가 안 맞는 카드가 섞인다. 달리는 중엔 알려 주지 않고, 한 장면에 2장 이상 들어가면 그 장면이 실패한다.

## 임무 고르기
타이틀의 **임무 고르기**에서 1 임무·2 임무로 바로 들어갈 수 있다(팀원이 반복해서 볼 때). 저장된 진행이 있으면 먼저 물어본다. 2 임무 브리핑의 안내 한 줄은 1 임무 기록이 있을 때만 바뀐다.

## 바로 들어가기(시험·조정용)
- `index.html?start=m1` / `?start=m2` — 그 임무부터
- `index.html?run=m1` / `?run=m2` / `?run=tutorial` — 달리기만(손맛 조정)

## 고치는 곳
- 손맛 수치(속도·판정 구간·가방 비울 칸·컨베이어 속도 등): `js/config.js`
- 장면·필요한 조합·카드 수·가짜·대사: `missions/m1.js`, `missions/m2.js`(컨베이어 물건 목록 포함), `missions/tutorial.js`, 인물 이름·색: `missions/cast.js`

결과는 실제 AI가 아니라 **단순화한 규칙**으로 만든 것이다(게임 끝에도 안내).

## 목적에 맞는 활용(2026-11-08)
데이터 관리 원칙의 첫째 기둥(목적에 맞게 쓰고, 목적 밖으로 쓰지 않는다·개인정보)을 1~4 임무에 더했다. 설계 `docs/specs/2026-11-08-data-purpose-design.md`.

- **목적 밖 개인정보 카드**(임무마다 2장, 흔한 모습 카드에만): 1 임무 신분증이 보이는 지갑·메시지 알림이 뜬 잠금화면 → 가리기 / 2 임무 캔을 버리는 사람 얼굴 → 빼기 / 3 임무 행인 얼굴·택시 번호판 → 가리기(흐리게·막대) / 4 임무 답안지의 학생 이름 → 가리기. 검수의 **크게 보기 → 가리기** 버튼(모든 카드에 있음). 처리하지 않고 제출하면 감독관이 막는다(어느 카드인지 말하지 않음). 끄고 켜기 = 임무 파일 `privacy.on`.
- **챕터 끝**(1~4 임무): 누군가 모은 데이터를 다른 데 쓰자는 메시지가 온다(1 ○○마트 마케팅팀 · 2 구청 단속 담당 · 3 근처 상점 광고 회사 · 4 ○○학원) → 셋 중 고르기(다시 고를 수 있음) → 이번 임무 개념 질문 하나 → 문장 틀로 짧은 생각 쓰기(비워도 됨). 답은 임무 완료 요약에 보이고, '처음부터'를 누르면 지워진다.

### 교사 검수 대기(초안 문장)
아래 문장은 **교사 검수 전 초안**이다(법적·교육적 정확성 미확인).
- 챕터 끝: 각 임무 파일 `missions/m1.js`~`m4.js`의 `chapterEnd`(요청 메시지·선택지·피드백·개념 질문·문장 틀), 공통 문구 `js/ui-chapter.js` TEXT
- 개인정보 카드: 감독관이 막는 대사·가리기 안내·결과 한 줄 `js/privacy.js` TEXT

## 글꼴(4 임무 손글씨)
4 임무 답안 카드의 손글씨는 무료 한글 손글씨 글꼴 4종을 **필요한 글자만 남겨**(데이터·알고리즘·인공지능·머신러닝·영문 d·a·t·A·I) `css/hw-fonts.css`에 base64로 넣고, Canvas로 기울기·떨림·굵기·크기를 바꿔 그린다(이미지 생성은 한글이 깨져 쓰지 않음).

| 게임 안 이름 | 원래 글꼴 | 만든 곳 | 라이선스 | 쓰는 곳 |
|---|---|---|---|---|
| HW Neat | Poor Story | YoonDesign Inc. | SIL OFL 1.1 | 반듯한 글씨 |
| HW Round | Gamja Flower | YoonDesign Inc. | SIL OFL 1.1 | 둥근 아이 글씨(반듯한 글씨의 다른 학생) |
| HW Quick | East Sea Dokdo | YoonDesign Inc. | SIL OFL 1.1 | 흘림 |
| HW Bold | Dokdo | FONTRIX | SIL OFL 1.1 | 아주 흘린 글씨(선배 글씨) |

- 라이선스 전문·저작권: `assets/fonts/OFL.txt`. 원본은 Google Fonts(github.com/google/fonts `ofl/`). 글자를 덜어 낸 수정본이라 원래 이름 대신 HW 이름으로 부른다. 나눔손글씨(펜·붓)는 OFL이지만 예약 글꼴 이름이 있어 덜어 낸 파일로 쓰지 않았다.
- 다시 만들기(글자를 더할 때): 저장소 **밖** 임시 폴더에 `npm i subset-font` → 원본 ttf를 받아 같은 글자 목록으로 woff2를 만들고 base64로 `@font-face`에 넣는다. 원본 글꼴 파일은 저장소에 올리지 않는다.
