# 데이터 러너: 끊어진 도시 — 튜토리얼 + 1 임무 + 2 임무

AI 학습 데이터를 직접 골라 모으며, 데이터를 "목적에 맞게" 관리하는 책임을 경험하는 3레인 러너.
기획: `data-runner-plan.md` · 제작 설계: `docs/specs/2026-10-27-data-runner-v1-design.md` · 가짜 카드 + 2 임무: `docs/specs/2026-10-28-data-runner-fakes-m2-design.md`

## 여는 법
1. 이 저장소의 **`data` 브랜치**를 받는다.
2. `data/index.html`을 **더블클릭**(인터넷·서버 필요 없음). Edge·Chrome 권장.
   - 더블클릭(`file://`)으로 열면 브라우저가 파일에서 읽은 사진을 "다른 출처"로 보아, 그 사진을 그린 카드 그림을 쓸 수 없다. 그때만 게임이 같은 사진을 담아 둔 `assets/cards/photos-embedded.js`(약 1MB)를 읽는다(배포 주소에서는 읽지 않음). **카드 사진(`assets/cards/{animals,lost-found,recycle,city}/*.webp`)을 바꾸면 `node assets/cards/embed-photos.mjs`로 다시 만든다** — 안 만들면 `tests/photos-embedded.test.mjs`가 실패한다. 이 파일이 빠지면 사진 대신 Canvas 그림으로 뜬다(멈추지는 않음).

## 흐름
타이틀 → 러너 프로필·독백 → 튜토리얼(개·고양이, 약 1분) → 1 임무 → 2 임무

- **1 임무 「분실물 센터 AI」**: 대화 → 브리핑 → 달리기(1분 30초) → 검수 → 감독관 → 접수대 컨베이어 → 결과 → 보충 → 마무리. 이름표가 다 맞아도 자료에 빠진 모습(접힌 우산, 열린 지갑, 뒤집힌 스마트폰)이 있으면 그 물건만 분류 보류로 남는다.
- **2 임무 「분리배출 분류 AI」**: 대화 → 브리핑 → 달리기 → 검수(**그림과 이름표가 안 맞는 카드의 이름표 고치기**) → 감독관 → **컨베이어 실제 분류**(처음 보는 물건 14개를 우리 AI가 분류함에 넣는 모습, 건전지가 엉뚱한 함으로 가면 비상 정지, 2배속·건너뛰기) → 장면별 결과 → (실패 시) 보충 → 선배 → 마무리

**가짜 카드**(1 임무부터): 그림과 이름표가 안 맞는 카드가 섞인다. 달리는 중엔 알려 주지 않고, 한 장면에 2장 이상 들어가면 그 장면이 실패한다.

## 임무 고르기
타이틀의 **임무 고르기**에서 1 임무·2 임무로 바로 들어갈 수 있다(팀원이 반복해서 볼 때). 저장된 진행이 있으면 먼저 물어본다. 2 임무 브리핑의 안내 한 줄은 1 임무 기록이 있을 때만 바뀐다.

## 바로 들어가기(시험·조정용)

- `index.html?run=m1` / `?run=m2` / `?run=tutorial` — 달리기만(손맛 조정)

## 고치는 곳
- 손맛 수치(속도·판정 구간·가방 비울 칸·컨베이어 속도 등): `js/config.js`
- 장면·필요한 조합·카드 수·가짜·대사: `missions/m1.js`, `missions/m2.js`(컨베이어 물건 목록 포함), `missions/m3.js`, `missions/m4.js`(채점 시연 답안지·결판 포함), `missions/tutorial.js`, 인물 이름·색: `missions/cast.js`

결과는 실제 AI가 아니라 **단순화한 규칙**으로 만든 것이다(게임 끝에도 안내).

## 목적에 맞는 활용(2026-11-08)
데이터 관리 원칙의 첫째 기둥(목적에 맞게 쓰고, 목적 밖으로 쓰지 않는다·개인정보)을 1~4 임무에 더했다. 설계 `docs/specs/2026-11-08-data-purpose-design.md`.

- **목적 밖 개인정보 카드**(임무마다 2장, 흔한 모습 카드에만): 1 임무 신분증이 보이는 지갑·메시지 알림이 뜬 잠금화면 → 가리기 / 2 임무 캔을 버리는 사람 얼굴 → 빼기 / 3 임무 행인 얼굴·택시 번호판 → 가리기(흐리게·막대) / 4 임무 답안지의 학생 이름 → 가리기. 검수의 **크게 보기 → 가리기** 버튼(모든 카드에 있음). 처리하지 않고 제출하면 감독관이 막는다(어느 카드인지 말하지 않음). 끄고 켜기 = 임무 파일 `privacy.on`.
- **챕터 끝**(1~4 임무): 누군가 모은 데이터를 다른 데 쓰자는 메시지가 온다(1 ○○마트 마케팅팀 · 2 구청 단속 담당 · 3 근처 상점 광고 회사 · 4 ○○학원) → 셋 중 고르기(다시 고를 수 있음) → 이번 임무 개념 질문 하나 → 문장 틀로 짧은 생각 쓰기(비워도 됨). 답은 임무 완료 요약에 보이고, '처음부터'를 누르면 지워진다.

- **같은 답안지 전후 비교**(4 임무 완료 화면): 답안 사진 · 처음 판정 · 내가 바꾼 자료 · 마지막 판정. 결과가 바뀐 답안지(틀림 → 맞음, 그리고 고치다가 **새로 틀린** 맞음 → 틀림 — 2026-11-10) 최대 3장 + 비교용 1장, 좁은 화면은 카드. 처음부터 다 맞았으면 한 줄. 첫 판정 기록은 저장의 선택 필드 `firstGrade`(옛 저장엔 없음 → 표 없음).

## 외부 리뷰 반영(2026-11-10)
검토 문서의 여섯 항목. 확정 결정(3D 러너·개인정보 보호 우선의 단순한 선택지·첫 제출 전 필요 장수 비공개·이름표 기준 집계·제한된 보충 횟수·실패를 포함한 이야기 완결)은 그대로.
1. **더블클릭 실행에서 사진 카드**: 위 「여는 법」 — 사진이 캔버스를 오염시키면 담아 둔 사진으로 바꿔 읽는다. 검수만이 아니라 브리핑·달리기도 같은 까닭으로 멈췄다.
2. **검수·보충 준비의 가방 변경은 바로 저장**: 이름표 고치기·빼기/되돌리기·설명표 붙이기·가리기. 새로고침해도 정리한 가방 그대로(연습은 저장 안 함).
3. **임무 뒤 활동 이어하기**: 임무를 끝낸 뒤 마지막 대화·챕터 끝·도시 복구·임무 완료 화면 도중에 나가면 타이틀 "이어하기"가 그 자리로 보낸다(저장의 선택 필드 `ending`, 옛 저장은 그대로). 완료 기록·도시 칸은 한 번만 센다. 임무 완료 화면에서 [타이틀로]·[다음 임무로]를 눌러야 끝난 것으로 친다 — 그 전에 나가면 완료 화면(4 임무는 토론 질문·비교표)을 다시 본다.
4. **4 임무 비교표**: 고치다가 새로 틀린 답안지도 보인다(위 절).
5. **크게 보기 창**: Tab·Shift+Tab이 창 안에서 돌고, 닫으면 열었던 카드로 포커스가 돌아온다. 창이 떠 있는 동안 배경은 누를 수 없다.
6. **저장 실패 안내**: 챕터 끝에서 저장이 안 되면 "저장했어" 대신 "저장하지 못했어. 지금 이 탭에만 남아 있어." 입력은 막지 않는다.

검사: 단위 `photos-embedded.test`·`ending.test`·`grade-compare.test` · 브라우저 `bare-browser`(보안 플래그 없이 = 더블클릭 조건)·`review-browser`(항목 2~6, `node tests/review-browser.mjs 3`처럼 하나만).

## 결승 "도착" 표지판 (2026-11-12)

결승선을 지나면 러너가 멈출 자리 앞 길 아래에서 "도착" 표지판이 솟아올라 살짝 튕기고 선다(three.js 장면 안의 판 하나 — 결승 게이트와 같은 체크무늬·남색 칸·노랑 글자·시안 기둥). 그다음은 예전처럼 화면이 어두워지며 "도착 · 가방 n/m" → 다음 화면.
- 시간: 솟기 0.5초(`config.finish.bannerRise`, 감속 1.2초 안) → 0.7초 가만히 → 0.8초 어두워짐. 끝맺음 전체 시간은 예전과 같다(감속·어두워짐 값은 안 바꿈). 자리 = 러너가 멈출 곳 6m 앞(`bannerAhead`), 화면 가로 가운데. 그동안 지나온 결승 게이트는 0.3초에 흐려져 사라진다(`gateFade` — 4 임무 휴대폰 화면에서 카메라가 게이트 현수막 속에 들어가 화면이 남색으로 덮이던 것도 함께 없어짐).
- HP 0("연결 끊김")엔 없다(게이트도 예전 그대로). 움직임 줄이기면 솟거나 튕기지 않고 처음부터 제자리에 보이고 게이트는 바로 사라진다(0.3초 페이드는 그대로).
- Space·클릭 건너뛰기는 그대로. 표지판의 메시·재질·텍스처는 달리기가 끝날 때 함께 치운다.
- 새 문장 없음("도착"은 원래 게이트 글자). 코드 `js/finish-banner.js`(계산) · `js/run3d.js makeFinishBanner`(그리기). 검사 단위 `tests/finish-banner.test.mjs` · 브라우저 `tests/finish-banner-browser.mjs`, 스크린샷 `_shot-finish-banner-{rise,rest}-{m1,m4}-{1280,390}`.

## 첫 화면 제목 글꼴 (2026-11-12)

리틱체(REATIC)는 동봉 라이선스의 이미지 제작 허용 범위로 사용했습니다. `assets/title-type/`의 PNG는 제목 글자만 포함하며, 리틱체 폰트 파일은 배포하지 않습니다. 실제 제목 텍스트는 HTML에 유지하고, 이미지 로딩 실패 시 기존 글꼴로 표시합니다. 장식 SVG·테두리는 화면 읽기에서 제외됩니다. 본문·버튼·다른 화면은 변경하지 않습니다.
