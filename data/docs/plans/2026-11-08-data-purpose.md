## 정한 것(설계의 '만드는 사람에게 맡김' 몫)

- **카드 표시 방식**: 개인정보 카드 = 그 임무 흔한 종류 카드 하나에 `privateId`를 붙인 것(진짜 종류 `key`는 그대로). 코스를 만든 뒤 정해진 규칙으로 고른다(난수를 쓰지 않음) → **카드 자리·uid·벽은 그대로, 필드 하나만 늘어남**. 첫 판 코스에만(보충 코스엔 없음).
  - 고르는 자리: 그 종류 카드 중 코스 앞 15% 밖, 정의의 `at`(0~1) 비율 위치.
  - 판정은 `key`로 세므로 가린 카드 = 그 종류의 정상 카드(설계 그대로).
- **데이터**: 임무 파일 `privacy: { on, cards: [{ id, key, fix: 'mask'|'remove', at, art, mask: [{ x,y,w,h, look:'bar'|'blur' }] }] }`. 공통 문구는 `js/privacy.js`.
  - m1: 신분증 보이는 지갑(`wallet_closed`), 메시지 알림 잠금화면(`phone_front`) — 가리기
  - m2: 캔을 버리는 사람 얼굴(`can_drink`) ×2 — 빼기
  - m3: 행인 얼굴이 또렷한 강변길(`river_now`), 택시 번호판이 또렷한 역 앞(`station_now`) — 가리기(흐리게·막대). 위험 조합(학교 앞 횡단보도)·시장 옛 사진은 피함
  - m4: 이름 칸에 흘림 획이 있는 또박또박 쓴 2·4(`neat_2`, `neat_4`) — 가리기
- **가린 모습**: `DR.Cards.artId` = `privateId`(가리면 `privateId#masked`) → 모든 그림 자리(달리기·검수·보충)가 같은 길로 그린다. 문서·번호판·이름 = 검은 막대, 얼굴 = 모자이크.
- **검수**: 크게 보기에 모든 카드 공통 '가리기' 버튼(개인정보 아닌 카드 → "가릴 개인정보가 없어"), 가린 카드엔 '가림' 표시, 검수 안내에 한 줄. 동기 고정 카드엔 없음.
- **감독관**: 제출 때 `DR.Privacy.check` → 처리 안 한 카드가 있으면 막음(어느 카드인지 말 안 함), 빼야 하는 카드를 가렸으면 그 문장으로 막음. 버튼은 '검수로 돌아가기'만.
- **결과**: 가릴 수 있는 카드를 뺐으면 마지막 장면에 "가렸으면 살려 쓸 수 있었어" 한 줄(`state.privCaught` = 첫 달리기 뒤 가방의 가리기 카드 id, 저장, 옛 저장 []).
- **테스트 훅**: `debugFill`은 개인정보 카드를 건너뛴다(기존 테스트 그대로), `privateId`로 부르면 그것만.
- **챕터 끝 화면** `#screen-chapter`(`js/ui-chapter.js`): 한 번에 한 단계(1/3 요청 → 2/3 개념 → 3/3 생각). 요청은 안내 AI 한 줄 + 메시지 카드 + 선택 3개(다시 고르기 가능, 피드백 한 줄, 고르면 [다음]). 개념 질문도 같은 방식. 생각 쓰기는 문장 틀(빈칸 두 개) + 입력마다 저장 + [마치기](비워도 됨).
- **저장**: `records[임무].chapter = { req: { first, last }, concept: { first, last }, note }` — `DR.Save.chapterOf(records, id)`가 옛 기록을 빈 값으로 맞춤. 바뀔 때마다 `setRecord`. 다시 깨면 이전 답을 채운 채 다시 보여 줌(처음 선택은 처음 값 유지).
- **요약**: `#outro-summary`에 "다른 용도 요청: …", "개념 질문: …", "내 생각: …".
- **스냅숏**: `walls-helper cardsOf`는 `privateId`를 빼고 비교(자리·uid가 그대로인지 지킴) + 새 테스트가 "개인정보 표시만 늘었다"를 따로 확인.
