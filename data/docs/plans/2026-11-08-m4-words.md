# 4 임무 낱말 손글씨 개편 — 구현 계획

설계: `docs/specs/2026-11-08-m4-words-design.md`(사용자 승인, 손글씨 = OFL 글꼴 + Canvas 변형). 옛 4 임무 설계 §5(`2026-11-01-data-runner-m3-m4-design.md`)의 흐름·엔진은 그대로 쓴다.
각 작업은 **실패하는 테스트 먼저 → 구현 → 통과 → 커밋**(`data` 브랜치, push 안 함).

## 정한 것(만드는 사람에게 맡긴 부분)

- **글꼴 4종(Google Fonts, SIL OFL 1.1, 예약 글꼴 이름 없음)** — 나눔 손글씨(펜·붓)는 OFL이지만 *예약 글꼴 이름(Nanum…)* 이 있어 글자를 덜어 낸 파일에 그 이름을 쓸 수 없다 → 쓰지 않음(MaruBuri 때와 같은 이유).
  - 반듯: **Poor Story**(YoonDesign) · 아이 글씨(둥근 반듯): **Gamja Flower**(YoonDesign) · 흘림: **East Sea Dokdo**(YoonDesign) · 아주 흘림(선배 글씨, 굵고 일정): **Dokdo**(FONTRIX).
  - 남기는 글자 = 데이터·알고리즘·인공지능·머신러닝·영문 a~z·A~Z·빈칸. woff2 → base64 → `css/hw-fonts.css`(file:// 더블클릭에서도 읽힘). 받기·덜어 내기 도구(`subset-font`)는 저장소 밖 임시 폴더.
- **이름표** = `data`(데이터)·`algo`(알고리즘)·`ai`(인공지능)·`ml`(머신러닝). 가짜에만 보기 밖 낱말 `date`('데이트')·`en_ai`('AI') = 버튼 없음(옛 7·8 자리). `labelStyle: 'word'` = 고치기·"?" 버튼이 낱말 4개, 375px 한 줄(안 되면 2×2).

- **결판** = 선배 답 = 아주 흘려 쓴 '머신 러닝'(띄어 씀, 정답 '머신러닝'). 읽음 ○ / 아주 흘림 빠짐 → '인공지능' ✕ / 띄어 쓴 표기 빠짐 → 보기에 없는 낱말 · 사람 채점. 동기 카드 = 아주 흘린 머신러닝 ×2 + '머신 러닝' ×2.
- **구역 배치**: 가짜 = 자기 구역 뒤쪽 절반(지금 규칙), ① = 드문 카드(앞에 벽). `rareLate`(1 임무 방식, 구역 앞은 평범한 카드)는 S2~S4에 평범한 카드가 없어 맞바꿀 짝이 없으므로 쓰지 않는다(엔진 그대로).
- **옛 저장**: 가방에 지금 임무에 없는 카드(종류·가짜·"?"·이름표)가 있으면 그 임무 브리핑으로(1 임무 침수 때와 같은 길, `DR.Save.fitsMission`). records.m4는 그대로.

## 작업

1. **글꼴** — 테스트 `fonts.test.mjs`(css에 @font-face 4개·woff2 머리·합계 크기·index.html 연결·OFL 문서에 저작권 4줄) → 덜어 낸 글꼴 css + `assets/fonts/OFL.txt` + index 연결.
2. **4 임무 데이터** — `m4.test.mjs` 새로(갈래 수·③ 4·①:② 비율·구역·판정·결판 보장·채점 시연·reach), 다른 단위 테스트의 옛 4 임무 키 바꾸기 → `missions/m4.js` 다시 쓰기, `cards.js`(이름표 짧은 글자·색), `stream.js`(가짜는 rareLate 맞바꿈 밖).
3. **옛 저장** — `save.test`(fitsMission) → `save.js`·`app.js resume`.
4. **그림** — `cardart-browser`(낱말 카드: 글꼴 읽힘·종류마다 다름·48칸 썸네일·단서·선배 답안) → `cardart.js drawWord`(글꼴 준비 전엔 캐시 안 함), 결과 컷·브리핑 샘플.
5. **화면** — `m4-browser`(낱말 버튼 375 한 줄, 흐름 A~F 낱말판) → `ui-inspect`(낱말 버튼)·`run3d`(큰 이름표)·`ui-grade`·`ui-result`·`ui-story`(결판 글)·`ui-story briefing`(답안 샘플)·CSS.
6. **문서** — README(글꼴 크레딧·교사 검수 대기)·CLAUDE.md ★·스크린샷 눈으로 확인·전체 테스트.
