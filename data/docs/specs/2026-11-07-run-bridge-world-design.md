# 달리기 무대 개편 1차 — 「도시 위를 잇는 빛의 다리」 설계

2026-11-07 · 사용자와 브레인스토밍(시각 시안 `run-look.html`·`run-look-c2.html`·`deck-color.html`, `.superpowers/brainstorm/3808-1794052132/content/`)

## 왜

사용자: "지금은 엑셀 위에서 달리는 느낌." 처음(연습) 보라 배경이 단조롭고, 달리는 맵 자체가 더 생동감 있었으면. **기존 게임을 망치지 않는 선에서** 더 좋은 게임이 되는 것.

진단(스크린샷 `tests/_shot-run-tutorial-1366.png`·`_shot-run-1366.png`):
- 바닥 = 보라 판 + 굵은 청록 레인 줄 + 가로줄(모눈종이). 화면에서 가장 밝은 것이 줄이라 카드보다 먼저 눈에 띈다.
- 옆 = 속이 빈 상자(보라 테두리 / 회색 덩어리)만 반복. 불빛·움직임 없음.
- 하늘 = 단색. 시작 화면엔 Codex 픽셀 도시(`assets/title/bg-*.webp`)가 있는데 달리기는 안 쓴다.

## 정한 것(사용자 결정)

1. **방향 C: 도시 위를 잇는 빛의 다리.** 하늘 → 지평선의 픽셀 도시(시작 화면 그림) → 다리 아래로 내려다보이는 어두운 도시 불빛 → 그 위를 지나는 빛나는 다리. 이야기("끊어진 도시를 데이터로 잇는다")와 맞아서. 비·젖은 반사·양옆 끊어진 케이블 스파크.
2. **바닥 = 시안 2번 "어두운 남색 철판".** 보라보다 어둡고 덜 붉은 남색(약 `#121228`~`#1a1a36`), 가로 격자줄 없앰(철판 이음매만 아주 흐리게), 레인 줄은 가늘고 흐리게(레인 위치를 알 정도), **가장 밝은 빛은 다리 양쪽 가장자리에만**, 젖은 바닥에 분홍·청록 네온이 은은히 비침. 이유: 눈이 덜 피곤하고 흰 카드·분홍 벽(노이즈)이 가장 잘 보임. (1번 지금 보라 = 배경에 묻힘, 3번 유리 = 반짝임이 카드를 가림 → 기각)
3. **적용 범위(1차):** 연습(튜토리얼) · 1 임무(분실물 센터) · 3 임무(길 안내). 2·4 임무는 **실내 무대(선별장·시험장)를 살려 2차에서 다듬는다** — 이번에 건드리지 않음.
   - 1 임무는 지금 2 임무 선별장을 임시로 빌려 쓰는 중(`missions/m1.js scenery:'sorting'`) → 다리로 옮긴다. 1 임무 자기 실내 무대(분실물 보관함)는 2차 이후 선택.
4. **3 임무 = 낮 다리.** 연습·1 임무는 밤 다리, 3 임무는 낮 버전. 낮 그림 3장(`bg-sky-day`·`bg-far-day`·`bg-mid-day`)은 사용자가 Codex에 맡김(밤 그림과 **같은 구도·실루엣**, 2026-11-07 프롬프트 전달). 파일이 오면 `assets/title/`에 들어온다.
   - **낮 다리 모습(2026-11-07 사용자 확인):** 바닥 = 밝은 청회색 철판(하늘보다는 어두워 흰 카드가 잘 보이는 정도), 가장자리 청록 빛은 낮이라 은은하게, 비·젖은 바닥은 지금처럼 학교 앞(S4)에만, 시장 골목(S2)은 지금의 저녁빛(등불) 유지. 낮 바닥 위 카드·벽 대비도 따로 검증한다.
5. **겉모습만.** 길은 곧은 3레인 그대로, 휘거나 오르내리는 길·터널은 나중 단계("기타 모습은 그다음").
6. **일러스트를 새로 그리지 않고 기존 그림 먼저.** 첫 시안의 "도시 밑 이상한 하늘 띠"는 일러스트 문제가 아니라 시안 레이어 순서 실수였다. 실제로 넣어 보고 어색하면 그때 필요한 한 장만 Codex에.

## 목표 / 비목표 / 반목표

- 목표: 첫 달리기(연습)부터 "데이터 세계 속 진짜 도시 위를 달린다"는 느낌. 속도감·깊이·생동감. 시작 화면과 한 세계로 이어짐.
- 비목표: 코스·카드·벽·불꽃 배치, 잡기·판정·저장, 속도·수치(`config.js`), 2·4 임무 무대, 길 모양 변화, 새 효과음/음악.
- **반목표(이러면 실패):**
  - 카드·벽·불꽃이 배경 때문에 덜 보이거나 헷갈림(가독성이 지금보다 나빠짐). 특히 배경 불빛이 카드 테두리색·벽 분홍과 겹쳐 보이면 안 됨.
  - 배경이 계속 번쩍여 눈이 피곤함(시안 3번이 기각된 이유).
  - 학교 저사양 PC에서 프레임이 눈에 띄게 떨어짐.
  - 그림 안에 글자·숫자(게임 원칙: 그림 안 글자 없음).

## 제약

- 클래식 `<script>` + 전역 `DR`, ES 모듈·fetch 금지(`file://`로 열림). three.js r149(`vendor/`).
- `?low=1` 저사양 모드 · `prefers-reduced-motion`: 비·스파크·흐르는 배경·바닥 반사 움직임을 끄거나 멈춘다(정적인 다리·하늘은 유지).
- `config.maxPixelRatio` 1.25 그대로. 이미지 추가는 webp(기존 bg 3장 합계 약 640KB 수준을 크게 넘지 않게).
- 3D 위 DOM 카드(가까운 카드)·`behindWall` 규칙·HUD는 그대로.
- 브라우저 테스트는 한 번에 하나씩(PC 메모리). `peek().scenery.theme`을 보는 테스트(m3 'city', m4 'exam', zones 'sorting')가 있다.

## 구성(무엇이 보이는가)

| 층 | 내용 | 출처 |
|---|---|---|
| 하늘 | 픽셀 하늘(밤 `bg-sky.webp` / 낮 `bg-sky-day`) | 기존 / Codex 대기 |
| 지평선 도시 | 먼 빌딩 + 중간 빌딩(끊어진 케이블·스파크) 2겹, 길이 사라지는 점 높이에 세움, 천천히 흐르는 시차 | `bg-far`·`bg-mid`(+낮) |
| 다리 아래 | 내려다보이는 어두운 도시 불빛(노랑·청록·분홍 점), 원근으로 흐름 | 코드 생성(3D 점) |
| 다리 | 남색 철판 바닥, 흐린 레인 줄, 가장자리 강한 청록 빛, 젖은 네온 반사 | 코드 |
| 다리 옆 | 끊어진 케이블 스파크(가끔), 비 | 코드 |
| 지금의 옆 상자 빌딩 | 다리 세계에선 빼거나 다리 아래 도시로 흡수(만드는 사람 판단) | — |

3 임무 구역(역 앞·시장 골목·강변길·학교 앞)은 지금처럼 **구역마다 조금씩 다르게** 보여야 한다(구역 HUD와 맞음). 지금의 구역 소품(시장 등불·강물·학교 앞 비)과 하늘 색조 차이를 낮 다리 위에서 살린다. 카드 그림 속 낮/밤·비는 그대로(판단 단서).

## 만드는 사람에게 맡김

- 3D 구현 방식(하늘·도시 그림을 큰 판/원통/배경 텍스처 중 무엇으로, 다리 아래 불빛 개수·흐름), 정확한 색 값·밝기·안개.
- 연습(구역 없음 → 지금은 `RunScenery` 없이 기본 장면)과 1 임무에 다리를 입히는 자리(기본 장면 `buildScene`을 바꿀지, 새 scenery 테마를 둘지). 단 2·4 임무의 지금 모습은 달라지면 안 된다.
- 낮 그림이 오기 전: 3 임무는 밤 그림을 밝게 물들인 임시 낮으로 두고, 파일이 오면 바꿔 끼운다(없어도 깨지지 않게 — 그림 못 읽으면 단색 하늘로).
- 테마 이름(`theme`)과 그에 맞춘 테스트 기대값 정리.

## 검토 뒤 정한 것(Claude 판단 — 사용자 확인 목록에 올림)

- **하늘·도시 그림은 3D 텍스처가 아니라 3D 캔버스 뒤의 CSS 배경층.** `file://`로 더블클릭해 열면 이미지를 WebGL 텍스처로 올리는 것이 브라우저 보안에 막힐 수 있다(테스트는 `--allow-file-access-from-files`라 통과해 버림). 시작 화면도 CSS 배경이라 같은 방식. 3D 캔버스는 투명 배경, 안개는 지평선 색에 맞춘다. 착수 전에 플래그 없이 더블클릭으로 직접 확인.
- **색이 카드·벽과 겹칠 때: 고른 색은 지키고 밝기·크기·위치로 양보.** 다리 아래 불빛은 작고 어둡게(카드 높이·레인 위로 오지 않게), 바닥 반사는 레인 바깥쪽에 흐리게, 분홍 반사는 벽이 서는 레인 가운데를 피한다. 다리 가장자리 청록은 카드 테두리(우산 `#4fb3ff`)와 겹치지 않게 레인 밖 바닥 높이에만.
- **1 임무 밤 다리도 구역마다 조금씩 다르게:** 구역마다 하늘 색조·다리 아래 불빛 색 비율만 살짝 바꾼다(선별장 무대가 구역마다 색이 바뀌던 신호를 잃지 않게). 연습은 구역이 없으니 한 가지.
- **이미지 용량은 한 세트(밤/낮) 기준 약 640KB.** 낮 세트는 3 임무에서만 읽는다(미리 받기 = 3 임무 브리핑).

## 검증

- 단위 230 · 브라우저 `run-all.mjs` 22개(백그라운드, 하나씩) 통과. 기존 코스 스냅숏 그대로.
- 스크린샷: 연습·1 임무·3 임무(구역 4개) × 1366·375, 그리고 2·4 임무가 **바뀌지 않았음**.
- 가독성: 바뀐 바닥 위에서 카드·벽·불꽃 대비(스크린샷 눈 확인 + 가능하면 카드 주변 화소 대비 수치).
- `?low=1`·reduced-motion에서 움직이는 배경 꺼짐 확인. 프레임은 헤드리스로 대략만(실기 PC 체감은 미확인으로 보고).
